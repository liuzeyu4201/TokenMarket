## 一、DeepSeek 官方 API

### 1.1 平台名称与套餐名称

- **平台名称**：DeepSeek（深度求索）
- **服务类型**：官方 API 开放平台（按量计费，无订阅套餐）
- **当前主力模型**：
  - `deepseek-v4-flash`（经济快速型）
  - `deepseek-v4-pro`（高品质推理型）
- **兼容别名**（即将弃用）：`deepseek-chat`、`deepseek-reasoner`（将于北京时间 **2026/07/24 23:59** 弃用）

### 1.2 定价（按量计费，精确到人民币/美元）

价格以 **每百万 tokens（1M tokens）** 为单位计费：

### 1.3 Token 额度或调用限制

- **无月度订阅额度**：纯按量计费，用多少扣多少。
- **并发限制**：
  - `deepseek-v4-flash`：2500 并发
  - `deepseek-v4-pro`：500 并发
- **动态限流**：在系统总负载较高时，基于系统负载和用户短时历史用量的动态限流模型可能导致 503 或 429 错误。暂不支持针对单个账号提高并发上限。

### 1.4 过期机制

- **充值余额**：**永久有效，不会过期**。
- **赠送余额**：有有效期，可在「账单」页面查看具体过期时间。
- **扣费优先级**：当充值余额与赠送余额同时存在时，**优先扣减赠送余额**。
- **退款政策**：
  - **未消费金额支持退款**。
  - 在线支付（支付宝/微信/PayPal/银行卡）：可在开放平台「账单」页面点击「退款管理」自助操作退款。
  - 企业对公转账：需填写工单，选择「申请退款」选项，按指引提交信息。
- **Rollover**：不适用（纯按量计费，无订阅周期概念）。

### 1.5 API 可用性

- **API Key**：**提供**，个人用户和企业用户均可申请。
- **获取难度**：**容易**。需完成实名认证（个人或企业）后，在平台创建 API Key 即可使用。
- **接口格式**：兼容 OpenAI API 格式 和 Anthropic API 格式，Base URL 分别为：
  - `https://api.deepseek.com`
  - `https://api.deepseek.com/anthropic`
- **工具生态**：已接入 Claude Code、GitHub Copilot、OpenCode 等主流 Agent 工具，可直接作为后端模型使用。

### 1.6 ToS 相关条款（使用限制摘要）

根据 DeepSeek 开放平台服务协议与官方文档：

- **禁止转售/共享 API Key**：用户需对 API Key 的保密性负全责，不应将其泄露给第三方。API Key 仅限账号持有人使用。
- **禁止逆向工程**：不得对服务进行逆向工程、反编译、解码或试图获取底层结构。
- **禁止竞争模型训练**：不得使用服务输出开发或训练与本服务具有竞争性的模型。
- **禁止违规内容**：不得输入或输出违反中国法律法规的内容（如色情、暴力、赌博、诈骗等）。
- **数据合规**：需遵守中国网络安全法、数据安全法、个人信息保护法等相关规定。

> **注**：DeepSeek 官方 ToS 为中文版本，主要面向中国法律框架。未在公开英文页面中发现针对 sublicensing 的专门条款，但 API Key 个人持有机制实质上限制了共享和 sublicensing。

## 二、Cursor（AI 代码编辑器）

### 2.1 平台名称与套餐名称

- **平台名称**：Cursor（由 Anysphere, Inc. 开发）
- **套餐层级**：
  1. **Hobby**（免费）
  2. **Pro**（$20/月）
  3. **Pro+**（$60/月）
  4. **Ultra**（$200/月）
  5. **Teams**（$40/用户/月）
  6. **Enterprise**（定制报价，联系销售）
- **计费模式**：订阅制 + 包含用量 + 超出后按用量计费（On-demand usage-based billing）

### 2.2 定价（月费/年费，精确到美元）

| 套餐 | 月费 | 年费（节省约 20%） | 目标用户 |
|---|---|---|---|
| **Hobby** | $0 | — | 初学者、轻度体验 |
| **Pro** | $20/月 | ~$192/年（约 $16/月） | 个人开发者、自由职业者 |
| **Pro+** | $60/月 | ~$576/年 | 每日使用 Agent 的用户 |
| **Ultra** | $200/月 | ~$1920/年 | Agent 重度使用者 |
| **Teams** | $40/用户/月 | — | 小型到中型团队协作 |
| **Enterprise** | 定制报价 | — | 大型企业、需要发票/采购订单 |

> **注**：年度订阅可节省约 20% 费用。Teams 和 Enterprise 无公开年付折扣信息。
> **重要变化**：2025 年中之前，Pro 套餐以「500 次 fast requests」为卖点；现在改为 **$20 月度使用额度（usage credits）**，按实际 token 消耗计算，重模型消耗更快。

### 2.3 Token 额度或调用限制（Fast / Slow Request 机制）

Cursor 的用量体系经历了重大改版，从「固定 fast request 次数」转向「月度使用额度 + 按需计费」。以下基于官方文档和社区信息综合整理：

#### 2.3.1 各套餐包含用量

| 套餐 | 包含用量 | 关键特性 |
|---|---|---|
| **Hobby** | 有限的 Agent 请求、有限的 Tab 自动补全 | 无法使用前沿模型（如 GPT-4、Claude） |
| **Pro** | $20/月 usage credits，无限 Tab 补全，扩展 Agent 限制 | 可访问 frontier models（Claude、GPT-4、Grok 等） |
| **Pro+** | 3× Pro 的 usage credits（约 $60/月等值） | 更高的 Grok & Composer 配额 |
| **Ultra** | 20× Pro 的 usage credits（约 $400/月等值） | 专为 Agent 重度用户设计 |
| **Teams** | 与 Pro 相同的个人用量，加上团队功能 | 集中计费、团队隐私模式、管理仪表板 |
| **Enterprise** | 池化用量（Pooled usage） | 全组织共享额度 |

#### 2.3.2 Fast vs. Slow Request 机制（历史机制与当前状态）

Cursor 历史上采用 **Fast / Slow** 双池机制：

- **Fast Requests**：优先路由，低延迟，立即响应。每个订阅包含一定数量的 fast requests（如旧版 Pro 的 500 次/月）。
- **Slow Requests**：当 fast 额度用完后，请求进入 slow pool。等待时间与已使用的 slow 请求数量成比例，通常在可控范围内，除非远超 fast 限制。
- **无限 Slow Requests**：在旧版体系中，slow requests 理论上是无限的（但速度较慢）。

**当前状态（2025 年中之后）**：
- Cursor 已转向 **usage-based billing（按用量计费）**，以 **$20 / $60 / $200 的月度 usage credits** 替代固定 fast request 次数。
- 当月度 included usage credits 消耗完毕后，用户可启用 **on-demand usage（按需计费）**，按实际 token/请求成本额外付费，费用在月末或达到 $20 阈值时结算。
- **Fast Request 包（Bundles）已弃用**：旧版可购买的 500 次 fast request 附加包已停止销售，现有用户可继续使用但无法购买新包。
- **消费限额**：用户可在仪表板设置美元消费限额，防止意外超额。达到限额后自动切换为 slow requests。

#### 2.3.3 模型分类与替代模型

Cursor 将模型分为两类：
- **Premium 模型**：前沿大模型（如 Claude 3.5/4 Sonnet、GPT-4o、Grok 等），消耗 credits 更快。
- **Other 模型**：轻量级/替代模型，消耗 credits 较慢。

用户可在仪表板分别配置 premium 和 other 模型的按需计费开关。

> **未找到公开信息**：当前各模型具体每次请求的成本明细（如 Claude vs GPT-4o 分别消耗多少 credits）未在公开页面完整列出，需登录仪表板查看。

### 2.4 过期机制

- **订阅周期**：按月计费，以首次购买日为「订阅结算日」（Subscription Billing Date），每月自动续订。
- **包含用量过期**：月度包含的 usage credits **按月重置**，未用完的 credits **不会 rollover** 至下月。
- **按需计费**：超出包含用量的 on-demand usage 按实际消耗计费，月末或达到 $20 阈值时出账单。
- **退款政策**：
  - 根据 ToS 第 4.1 条：「所有费用均以美元计价且**不予退还**，法律另有规定的除外。」
  - 如果 Anysphere 主动终止订阅（非因用户违约），将**按比例退还**终止后订阅剩余部分已支付的费用。
  - 用户可在续订日前 24 小时取消订阅，避免下一周期扣费。
- **Rollover**：**不支持**，每月额度不累积。

### 2.5 API 可用性

- **Cursor API / SDK**：Cursor 提供 API 和 SDK，允许开发者将 Cursor 账户能力集成到自己的应用中。
- **BYOK（Bring Your Own Key）**：Cursor 支持用户绑定自己的第三方 API Key（OpenAI、Anthropic、Google、自定义 OpenAI-compatible endpoint），在 Cursor 设置 → Models 中添加即可。
  - **注意**：BYOK 仅覆盖模型请求本身；部分功能（Tab 补全、Cursor 原生 Agent、Background Agents 等）仍依赖 Cursor 基础设施，需要活跃订阅。
- **API Key 获取**：Cursor 的 API/SDK 使用与 Cursor 账户绑定，不需要单独申请 API Key（使用账户凭证）。

### 2.6 ToS 相关条款（禁止共享、转售、Sublicensing）

根据 Cursor《服务条款》（Terms of Service，2026-01-13 版本）核心限制：

| 条款 | 原文/摘要 | 严厉程度 |
|---|---|---|
| **1.5(iii) 禁止出租/出售服务** | 「您不得：出租、租赁、出借或出售本服务」 | 🔴 严格禁止 |
| **1.5(v) 禁止竞争模型训练** | 「不得使用本服务或任何 Suggestions 开发或训练与本服务具有竞争性的模型，或从事模型提取或窃取攻击」 | 🔴 严格禁止 |
| **1.5(vii) 基准测试限制** | 「不得向任何第三方提供对本服务进行的任何基准测试结果，除非包含足以使他人得以复制该等测试的所有必要信息」 | 🟡 有条件允许 |
| **账号共享** | 第 3 条：您应对账户和密码的保密承担全部责任，对在账户下发生的所有活动负全责。 | 🟡 实质上禁止共享 |

- **允许**：将 Cursor 作为技术栈的一部分嵌入自己的产品中（如后端 AI 服务），只要不是在转售 Cursor 本身。
- **禁止**：使用 Cursor 输出训练竞争性模型。
