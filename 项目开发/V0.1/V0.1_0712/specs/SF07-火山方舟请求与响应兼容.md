# Feature Specification: SF07 火山方舟请求与响应兼容

**Feature ID**: `SF07`  
**Short Name**: `volcano-openai-compatibility`  
**Created**: 2026-07-13  
**Status**: Draft  
**Source**: 周度 Spec F05、路线图火山方舟兼容目标、Go 适配器规范

## 目标与价值

在不暴露火山方舟差异的前提下，为代理主链路提供 OpenAI-compatible Chat Completions 与火山方舟之间的双向兼容。买家后续只需替换 Base URL 和代理 Key，不需要为火山方舟重写请求或解析逻辑。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 转换非流式聊天请求与响应 (Priority: P1)

作为代理调用方，我希望标准 Chat Completions 请求在火山方舟执行后仍返回兼容响应。

**Independent Test**: 使用标准兼容测试集输入非流式请求，对比转换前后的模型、消息、采样参数、choices、finish_reason 和 usage 语义。

**Acceptance Scenarios**:

1. **Given** 请求只使用 V0.1 支持字段，**When** 转换并发送到受控火山方舟契约，**Then** 模型、消息顺序和生成参数语义保持一致。
2. **Given** 火山方舟返回正常非流式结果，**When** 转换响应，**Then** 返回兼容的 id、object、created、model、choices、finish_reason 和 usage。
3. **Given** 请求包含不支持字段或非法类型，**When** 转换前校验，**Then** 返回明确参数错误，不静默丢弃会改变用户意图的字段。

---

### User Story 2 - 转换流式事件 (Priority: P1)

作为流式代理能力，我希望每个火山方舟响应块被转换为有序兼容事件，并以 `[DONE]` 正确结束。

**Independent Test**: 以多块、拆包、合包和末块 usage 的受控事件流验证转换结果及顺序。

**Acceptance Scenarios**:

1. **Given** 上游发送流式 delta，**When** 转换事件，**Then** role、content、finish_reason 和索引语义保持一致。
2. **Given** 上游正常结束，**When** 处理末块，**Then** 可用 usage 被保留且只输出一次兼容终止标记。
3. **Given** 单个事件跨网络块拆分，**When** 流解析，**Then** 在事件完整前不输出损坏 JSON。

---

### User Story 3 - 稳定映射上游失败 (Priority: P2)

作为代理网关，我希望认证失败、权限失败、限流、超时和非法响应映射为稳定错误类别，以便 SF12/SF15 决定客户端响应和 Key 状态。

**Acceptance Scenarios**:

1. **Given** 上游返回 401、403、429 或 5xx，**When** 适配响应，**Then** 输出对应稳定分类并保留安全的上游状态。
2. **Given** 上游响应正文包含敏感信息，**When** 生成错误，**Then** 对外与日志只包含脱敏摘要。

### Edge Cases

- 空 messages、未知 role、空 content 或极大请求体。
- 火山方舟模型名称与公开兼容模型名称不一致。
- 正常 HTTP 状态但响应缺少 choices 或 usage。
- usage 只出现在流末块、完全缺失或数值不自洽。
- SSE 中存在注释、空行、多行 data、未知事件和半个 UTF-8 字符。
- 客户端取消后仍到达的上游事件。
- 上游加入新字段或错误字段类型变化。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: V0.1 MUST 支持 OpenAI-compatible `chat/completions` 的非流式和流式语义；其他端点返回不支持。
- **FR-002**: 请求转换 MUST 保留 model、messages、stream、temperature 和 max_tokens 等已声明支持字段的语义。
- **FR-003**: 支持字段清单、取值范围和默认行为 MUST 形成版本化契约；未知字段不得在未定义策略下静默改变结果。
- **FR-004**: 非流式响应 MUST 标准化 id、object、created、model、choices、finish_reason 和可用 usage。
- **FR-005**: 流式响应 MUST 保持事件顺序、delta 语义和唯一终止标记；解析必须跨网络分块正确工作。
- **FR-006**: usage MUST 标准化为 prompt_tokens、completion_tokens 和 total_tokens，并校验总数不小于分项之和。
- **FR-007**: usage 缺失 MUST 作为显式状态传递给 SF17，不得用零值伪装官方计量结果。
- **FR-008**: 上游 401、403、429、超时、5xx 和非法响应 MUST 映射到稳定错误类别，并保留是否可重试信息。
- **FR-009**: 转发请求头 MUST 采用允许列表；不得把买家代理 Key、内部令牌或无关客户端头发送给火山方舟。
- **FR-010**: 返回头 MUST 采用允许列表，移除上游可能泄露基础设施或敏感信息的字段。
- **FR-011**: 转换层 MUST NOT 负责买家认证、卖家 Key 选择、凭证持久化或公开 HTTP 响应写入。
- **FR-012**: 新增其他平台适配时 MUST 不修改本功能的火山方舟兼容规则或路由核心契约。

### Engineering Requirements *(mandatory)*

- **ER-001 — Contracts**: OpenAI-compatible 输入、输出、SSE 和错误分类必须有机器可校验 Schema/黄金测试；破坏性变化使用新契约版本。
- **ER-002 — Security & Privacy**: 请求和响应正文默认不得记录；原始 Key 只通过受控认证头使用，所有错误先脱敏再传播。
- **ER-003 — Data Integrity**: Token 数使用整数并校验非负和总数关系；模型映射必须确定且可追踪原始/公开名称。
- **ER-004 — Performance & Capacity**: 非流式转换自身 P95 小于 5 毫秒；流式单事件转换 P95 小于 1 毫秒且不聚合完整响应。
- **ER-005 — Reliability**: 上游调用采用有界超时并传播取消；转换失败不得产生部分伪造的成功响应。
- **ER-006 — Observability**: 记录平台、公开模型、转换结果、错误类别和耗时，不记录消息正文或凭证；提供兼容测试失败指标。
- **ER-007 — Accessibility**: V0.1 无前端；兼容响应为开发者 API，错误需具备稳定代码和可操作说明。

### Failure and Recovery Scenarios *(mandatory)*

1. **Given** 非流式上游响应缺失必需字段，**When** 转换，**Then** 返回 invalid_response，不输出看似成功的兼容对象。
2. **Given** 流式连接在事件中途断开，**When** 解析器收到 EOF，**Then** 报告截断错误并保留已完成事件顺序，不补造 `[DONE]`。
3. **Given** 上游契约新增字段，**When** 现有兼容解析运行，**Then** 向后兼容字段可安全忽略；影响语义的变化由契约测试阻止发布。

### Key Entities

- **Compatible Chat Request**: 公开模型、消息、有界生成参数和 stream 标记；用户内容属于敏感数据，不持久化于本功能。
- **Provider Request/Response**: 火山方舟契约表示，只在一次调用期间存在。
- **Compatible Stream Event**: 有序 delta、完成原因、可选 usage 和终止状态。
- **Usage Observation**: 官方返回的 Token 分项、完整性状态和来源。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 火山方舟兼容标准测试集通过率为 100%，这是 V0.1 Go/No-Go 必需指标。
- **SC-002**: 非流式转换 P95 小于 5 毫秒；流式事件转换 P95 小于 1 毫秒。
- **SC-003**: 100% 受支持字段在往返测试中语义保持，所有不支持字段获得确定结果。
- **SC-004**: 401、403、429、超时、5xx、非法响应和截断流分类准确率为 100%。
- **SC-005**: 1 万个多样化流事件的顺序、边界和终止标记测试零丢失、零重复。
- **SC-006**: 日志与错误扫描不出现消息正文、买家代理 Key 或卖家原始 Key。

## Scope

### In Scope

- 火山方舟 Chat Completions 请求、非流式响应、SSE 事件、usage 和错误分类转换。

### Out of Scope

- Embeddings、Models 列表、多平台、公开代理 Handler、路由、认证、计费和用量持久化。

## Test Requirements

- 黄金文件与 Schema 测试覆盖请求/响应兼容。
- 流解析测试覆盖拆包、合包、UTF-8、末块、usage 缺失和截断。
- Mock 适配器测试覆盖全部 HTTP 状态、超时和取消。
- 模糊测试针对 JSON/SSE 解析器，确保非法输入不 panic。
- 适配器领域包至少 80% 行覆盖，错误映射和边界分支直接覆盖。

## Assumptions

- 依赖 SF06 已建立火山方舟客户端、错误分类和当期官方契约基线。
- V0.1 只承诺 Chat Completions；支持字段最终以兼容测试集清单为准。
- SF12/SF15 负责公开传输，SF17 负责 usage 持久化。
