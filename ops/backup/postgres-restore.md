# PostgreSQL 备份恢复（V0.2 目标）

- **RPO**: ≤ 5 分钟（连续归档或 ≥1 次/5 分钟的基准备份）。
- **RTO**: ≤ 30 分钟（非生产演练计时墙钟）。
- **范围**: 业务事实源（用户、Project、Binding、账本）。Redis 不在本恢复路径中充当 SoR。

## 非生产演练

1. 对隔离实例拍摄备份（base backup + WAL 或逻辑备份）。
2. 恢复到新的空卷/实例，不覆盖源。
3. 记录备份点时间与恢复完成时间，验证 RPO/RTO。
4. 抽查账本分录可查询且无静默截断。

在授权的容量/恢复窗口（SF33）之前，本手册是必做资产；不得用未演练备份宣称公开上线。
