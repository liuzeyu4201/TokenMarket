## 一、Kimi 月之暗面（Moonshot AI）

### 1.1 平台概述

Kimi由月之暗面（Moonshot AI）开发，创始人杨植麟。公司以长文本处理能力（Long Context）起家，2025年转向开源战略，推出Kimi K2系列MoE架构基座模型。2025年10月正式推行大规模付费协议，包括面向普通用户的会员订阅和面向开发者的API阶梯计费。截至2025年底，月之暗面现金持有量超过100亿元人民币，付费用户月增速约170%。

### 1.3 开放平台 API 定价（按量计费）

#### 计费基础
- **按 Token 计费**：每次 API 调用分别计算输入 Token 和输出 Token 费用
- **Token 单位**：1M = 1,000,000 tokens
- **联网搜索**：每次调用额外收费 **¥0.03**（独立于 Token 消耗）
- **文件相关接口**（文件内容抽取/文件存储）：**限时免费**

| **kimi-k2.7-code** | ¥6.5 | ¥1.3 | ¥27 | 262,144 |
| **kimi-k2.7-code-highspeed** | ¥13 | ¥2.6 | ¥54 | 262,144 |
| **kimi-k2.6** | ¥6.5 | ¥1.3 | ¥27 | 262,144 |

**Context Caching（上下文缓存）：** 缓存命中部分的 Token 按优惠价格（约20%原价）计费，可有效降低重复上下文的使用成本。
