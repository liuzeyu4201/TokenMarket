# V0.2 SF 文档完整性检查表

创建或评审每个 SF 时逐项确认：

- [ ] 功能目标和用户价值明确，不以实现技术代替需求。
- [ ] 前置依赖与产生的契约/数据/事件明确。
- [ ] In Scope、Out of Scope 和跨版本边界明确。
- [ ] 正常流程、失败流程、幂等、并发和权限边界明确。
- [ ] 多租户隔离、凭据脱敏和审计要求明确。
- [ ] 涉及协议时，端点目录、原生错误、流式/工具/文件语义明确。
- [ ] 涉及账务时，价格版本、精度、分录和对账规则明确。
- [ ] 每条验收标准可测量，并注明测试层级或证据。
- [ ] 性能、可靠性、可观测性和回滚要求已覆盖或明确不适用。
- [ ] 没有充值、提现、法币锚定和跨协议转换等 V0.2 排除项。
- [ ] 未留下 `TODO`、模糊的“支持全部”或无法判定的“体验良好”。
- [ ] 已建立 requirement → test → result → artifact 追踪。
