### 2.2 API Rate Limits（速率限制）— 使用层级（Usage Tiers）

OpenAI API 限制分 **RPM**（每分钟请求数）、**TPM**（每分钟 token 数）、**RPD**（每日请求数）、**TPD**（每日 token 数）、**IPM**（每分钟图像数）等维度。限制按 **Organization + Project** 级别施加，非用户级别。

| 层级 | 资格条件 | 月度使用上限 | 典型 RPM/TPM（GPT-5.5 示例） |
|------|----------|-------------|---------------------------|
| **Free** | 新账户，位于允许地区 | $100/月 | 极低（约 3–20 RPM） |
| **Tier 1** | 累计付费 $5 | $100/月 | 500 RPM / 200K TPM |
| **Tier 2** | 累计付费 $50 + 首次付费后 7 天 | $500/月 | 5,000 RPM / 2M TPM |
| **Tier 3** | 累计付费 $100 + 首次付费后 7 天 | $1,000/月 | 5,000 RPM / 4M TPM |
| **Tier 4** | 累计付费 $250 + 首次付费后 14 天 | $5,000/月 | 10,000 RPM / 10M TPM |
| **Tier 5** | 累计付费 $1,000 + 首次付费后 30 天 | $200,000/月 | 10,000–30,000 RPM / 150M+ TPM |

> **关键规则**：
> - 层级晋升**自动发生**，无需提交工单；但等待期是硬性日历日要求，即使一天消费 $10,000 也需等满 30 天才能到 Tier 5。
> - Free 层级新账户获得 **$5 免费 API 信用额度**（用于测试）。
> - 免费试用额度（如有）通常 3 个月内过期。
> - 各模型的具体 RPM/TPM 数字差异很大，轻量模型（nano/mini）的 RPM 远高于旗舰模型。

### 2.3 API 计费与预付机制（Prepaid Billing）

| 字段 | 内容 |
|------|------|
| **计费模式** | 预付制（Prepaid Credits）—— 必须先购买信用额度，API 调用实时扣减 |
| **最低充值** | $5/次；默认建议 $10 |
| **最大单次充值** | $5,000（高信任 tier 可更高） |
| **额度过期** | ⚠️ **购买的信用额度自购买之日起 1 年后过期**，未使用额度**作废且不可退款** |
| **Rollover** | 否。过期额度不延期、不结转 |
| **自动充值** | 可设置 Auto-recharge：当余额低于阈值时自动扣信用卡充值；可设月度充值上限 |
| **退款政策** | 官方明确：**API 信用额度不可退款**（除法律强制要求外） |
| **负余额** | 系统切断访问可能有延迟，期间产生的超额使用会显示为负余额，下次充值时优先抵扣 |
| **免费 vs 付费额度** | 免费额度（如有）优先使用，然后才是购买的付费额度 |

> **社区强烈争议**：大量开发者反映 OpenAI 的 1 年过期政策极不友好，过期前几乎不发送提醒，购买确认邮件/发票/账单页面均未明确标注过期时间，仅在“Credit Grants”标签页显示。已发生多起 $1,000+ 额度无故过期案例，支持团队以“政策如此”拒绝恢复。

## 三、ToS / 服务协议关键条款（禁止共享、转售、子授权）

### 3.1 个人服务《使用条款》（Terms of Use，2026-01-01 生效）

| 条款 | 原文/摘要 |
|------|----------|
| **账户共享** | “您不得分享您的账户凭据或让其他人使用您的账户” |
| **出租/出售** | “您不得修改、复制、出租、出售或分发我们的服务” |
| **逆向工程** | 禁止尝试或协助第三方对服务进行逆向工程、反编译或获取源代码及底层组件 |
| **竞争模型** | 禁止利用输出内容开发与 OpenAI 构成竞争关系的模型 |
| **自动化提取** | 禁止自动或以编程方式提取服务中的数据或输出（除非通过 API） |
| **规避限制** | 禁止干扰或破坏服务，包括规避任何速率限制或绕过保护措施 |
| **虚假陈述** | 禁止就非人类生成的输出，作出该内容系人类生成的虚假陈述 |

### 3.2 商业服务《服务协议》（Services Agreement，2026-01-01 生效）

该协议适用于 API、ChatGPT Enterprise、Business、ChatGPT for Clinicians 等商业/开发者客户。

| 条款 | 原文/摘要 |
|------|----------|
| **3.1 客户账户** | “客户不得在多名用户之间共享账户登录凭据或个人登录凭据。客户不得**转售、出租**自身账户或任意最终用户账户的访问权限。” |
| **3.2 最终用户** | “最终用户账户仅可分配给单一最终用户、为该用户注册，且仅能由该单一最终用户使用。” |
| **3.3(g) API 密钥转让** | “与第三方**买卖、转让 API 密钥**”——明确禁止。 |
| **3.3(h) 规避限制** | 禁止干扰、破坏服务运行，包括规避速率限制、各类管控规则，绕过服务防护、安全缓解机制。 |
| **3.3(i) 使用限额** | 禁止违反、规避使用限额，或通过配置服务规避使用限额约束。 |
| **数据训练** | 商业客户数据默认**不用于模型训练**（Consumer 计划需手动 opt-out）。 |
| **仲裁条款** | 争议通过 NAM 仲裁解决；禁止集体诉讼（class action waiver）。 |

> **法律风险评级**：OpenAI 对账户共享、API Key 转售、子授权（sublicensing）的禁止是**明确且强硬**的。违规后果包括：暂停/终止账户、删除内容、没收未使用额度。协议中未提及“首次警告”机制，OpenAI 保留单方面立即处置权。

| **支持卡片** | 信用卡、借记卡（Visa、Mastercard、Amex 等主流卡组织） |
| **不支持** | 预付卡（Prepaid cards）通常被 Stripe 风控拒绝；部分虚拟卡也被拒绝 |
| **应用内购买** | iOS/Android 可通过 Apple/Google Play 支付，按本地货币计费，账单路径与网页版不同 |
| **地区限制** | 用户所在地和**发卡行所在国**均需在 OpenAI 支持列表内（约 89 个国家/地区支持 ChatGPT 付费）；否则会出现 “Payment method not available in your region” |
| **3DS 验证** | 欧洲、亚洲等多地需完成 3D Secure / OTP / 银行 App 验证 |
| **企业账单** | Business/Enterprise 支持发票、银行转账、集中账单 |

### 5.2 API 平台支付

| 项目 | 说明 |
|------|------|
| **支持卡片** | 标准信用卡/借记卡（必须是支持国际在线支付的实体卡或标准银行发行卡） |
| **明确禁止** | 预付卡（Prepaid cards）**不可用于购买 API 信用额度**（OpenAI 官方 Help Center 明确说明） |
| **地区限制** | 用户和发卡行需均在 API 支持国家/地区列表内（名单与 ChatGPT 支持名单略有不同） |
| ** Billing 地址** | 必须与银行记录完全匹配，地址不匹配是支付失败最常见原因 |
| **发票/账单** | 高用量 Enterprise 客户可协商月度发票；自服务用户仅限信用卡 |
| **最低充值** | $5 起充 |
| **最大余额** | 受信任 tier 限制，新账户通常有较低上限（约 $50–$100） |

> **常见支付失败原因**：
> 1. 卡信息错误（卡号、过期日、CVC、账单地址邮编不匹配）
> 2. 银行拦截跨境/重复扣款（需联系银行放行）
> 3. 使用预付卡/虚拟卡/礼品卡（API 明确禁止）
> 4. 地区不支持（用户 IP 或发卡国不在支持列表）
> 5. 3D Secure 验证失败（浏览器拦截弹窗、未收到 OTP）
> 6. 企业防火墙/VPN 干扰 Stripe 风控

## 六、额度/余额过期机制汇总

| 计划类型 | 额度类型 | 是否过期 | 过期时间 | Rollover | 退款政策 |
|----------|----------|----------|----------|----------|----------|
| ChatGPT Free | 免费消息额度 | 否（自然恢复） | 按小时重置 | 不适用 | 无 |
| ChatGPT Go/Plus/Pro/Business | 订阅消息/功能额度 | 是（按月重置） | 每月账单日 | 否 | 已付月费不退 |
| API 免费试用额度 | 促销信用 | 是 | 通常账户创建后 3 个月 | 否 | 否 |
| API 购买信用额度 | 预付 Credits | **是（强烈注意）** | **购买后 1 年** | **否** | **不可退款** |
| API 月度用量（Post-paid） | 已用即消 | 是（实时） | 实时扣减 | 否 | 按账单付费，无 refund |
| Enterprise 合同 | 合同承诺 | 按合同期 | 合同约定期限 | 可协商 | 按合同条款 |

> **核心风险提示**：OpenAI API 的“1 年过期”政策是**所有主流 AI 平台中最严格之一**，且过期前提醒机制极弱。开发者应避免一次性大额充值，建议按 3–6 个月预计用量分批购买。

## 七、关键发现与对比总结

| 维度 | OpenAI 特点 | 风险提示 |
|------|-------------|--------|
| **定价复杂度** | 极高：7 个 ChatGPT 消费 tier + 5 个 API 使用 tier + 多模型按量计费 | 用户极易混淆 ChatGPT 订阅与 API 计费 |
| **额度透明度** | 消费级是“消息计数”而非 token；API 是精确 token | 难以直接对比 ChatGPT Plus 与 API 成本 |
| **过期政策** | API 购买额度 1 年过期，不可退款，不 rollover | 开发者社区强烈不满，存在资金损失风险 |
| **ToS 执行** | 明确禁止账户共享、API Key 买卖、子授权 | 违规代价高（封号、额度清零），灰色市场仍有交易但不受保护 |
| **地区/支付** | 支持约 89 国 ChatGPT / 略少国家 API；预付卡 API 禁用 | 中国区/部分中东/非洲国家支付困难 |
| **模型迭代速度** | 极快（2026 年已迭代至 GPT-5.5/5.6） | 旧模型（GPT-4o、GPT-5 早期版本）已退役，价格表频繁更新 |
| **企业合规** | Enterprise 提供 SOC 2、数据驻留、自定义法律条款 | 中小企业只能通过 Business 获得基础合规 |
