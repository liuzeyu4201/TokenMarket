# SF07 单会话与认证安全加固

**优先级：** P0　**依赖：** SF03、SF06

## 功能描述

每个普通账户同一时刻只允许一个有效 Web 会话。新登录必须原子撤销旧会话并在 1 秒内跨节点生效；代理 Key 生命周期不受 Web 会话替换影响。

## 功能要求

- 会话使用不可预测、可轮换的凭据；cookie 开启 Secure、HttpOnly、SameSite 和明确过期策略。
- 新登录在单事务中提升 account session generation；所有请求校验 generation。
- 支持主动退出、全部退出、异常登录提醒和账户安全页查看当前会话摘要。
- 状态变更请求使用 CSRF 防护；登录/验证接口具备暴力破解与自动化防护。
- 认证事件记录结果、设备/IP 摘要和 request ID，不记录 token。

## 边界与异常

单会话仅指平台 Web 会话；代理 Key 可同时服务多个合法客户端，其并发由 Key/Project 策略控制。缓存异常时不能让已撤销会话复活。

## 验收标准

1. 两设备同时登录同一账号，数据库只保留一个当前 generation。
2. 第二次登录完成后 1 秒内，第一设备在所有 API 节点收到会话失效响应。
3. 会话替换不禁用、不轮换任何代理 Key。
4. Redis 重启、节点切换和浏览器重放旧 cookie 均不能恢复旧会话。
5. CSRF、session fixation、token 猜测和暴力验证负向测试通过。
6. 主动退出立即失效且审计可按账号和 request ID 查询。

## 验收证据

多设备 E2E、跨节点撤销计时、cookie 安全检查、认证安全测试与审计样例。
