# SF13 Project 预算、测试额度、用量与开发者引导

**优先级：** P0　**依赖：** SF10、SF11、SF12、SF28

## 功能描述

为买家提供从创建 Project 到成功发出第一条原生协议请求的完整引导，并展示预算、测试额度、用量、扣减和错误诊断。所有资产明确标注为不可购买、不可提现的测试额度。

## 功能要求

- 支持 Project 总预算和可选协议/Key 子预算，达到软阈值告警，硬阈值拒绝新请求。
- 总览展示 available、reserved、settled、unresolved，不能把未决金额算作免费。
- 按 OpenAI/Anthropic/Vertex 生成原生 curl/SDK 示例，base URL 和 Key 注入方式正确，不做协议转换。
- 用量可按时间、协议、模型、Key、Connection/路由结果和结算状态筛选导出。
- 首次使用 checklist 覆盖 Binding、Key、测试调用和结果解释。

## 边界与异常

不提供充值按钮、支付链接、法币余额或“提现收益”。预算不是最终成本上限时必须解释 reservation 与异步调整。

## 验收标准

1. 新买家可在 10 分钟内按 UI 引导完成任一协议首个成功请求。
2. 三协议示例使用各自原生 SDK/字段，并通过自动冒烟。
3. 软阈值只告警，硬阈值在并发条件下不接受超过可用额度的新 reservation。
4. 页面聚合与不可变账本抽样 100% 一致，可下钻到 request ID。
5. unresolved 有原因、后续动作和更新时间，不显示为 0 成本。
6. 全站搜索不到充值、提现、可兑换或与人民币 1:1 等误导表述。

## 验收证据

新用户计时测试、SDK 冒烟、预算并发测试、账本对账和文案扫描。
