# SF23 共享路由资格过滤与自买自卖排除

**优先级：** P0　**依赖：** SF09、SF11、SF12、SF15、SF16、SF18

## 功能描述

共享路由先执行不可妥协的资格过滤，再允许评分。只有协议、端点、模型、状态、容量、价格、权限和所有权均合格的 Connection 才能进入候选集。

## 功能要求

- 过滤顺序与拒绝原因版本化；至少检查 mode、protocol、catalog endpoint、capability、model/region、health floor、quota/capacity、price validity。
- 按账户不可伪造 owner ID 排除买家本人及受其控制的卖家 Connection。
- preview/beta 还需同时满足目录可用、Project opt-in 和 Connection capability。
- 过滤结果生成 route decision 候选摘要和原因码，不记录敏感凭据。
- 无候选时返回稳定可操作的平台错误，不降级到不合格连接。

## 边界与异常

评分不能挽救硬门槛失败者。专享 Connection 永远不进入共享候选集；有状态端点在共享模式直接拒绝。

## 验收标准

1. 每个硬门槛均有单独失败 fixture 和组合属性测试。
2. 10 万次随机路由中不出现协议/模式/能力不匹配连接。
3. 双角色及关联 owner 的自买自卖选择次数为 0。
4. 无候选时不会调用 upstream，错误包含安全的失败类别和 request ID。
5. 配置并发变更时每次过滤只使用一个完整快照版本。
6. route decision 可重放得到同一候选集。

## 验收证据

过滤矩阵、属性测试、owner 排除测试、无候选 E2E 和决策重放报告。
