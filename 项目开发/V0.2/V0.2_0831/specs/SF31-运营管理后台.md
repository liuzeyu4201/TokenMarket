# SF31 用户、连接、Project、价格、路由与账本运营后台

**优先级：** P0　**依赖：** SF17、SF24、SF25、SF29、SF30

## 功能描述

提供覆盖平台主要运营对象的管理员控制台：用户/会话、Provider Connections、Projects/Bindings、价格、路由策略、专享更换、账本/未决、告警与审计。

## 功能要求

- 列表支持安全搜索、分页、筛选、导出权限和可分享的非敏感查询状态。
- 对象详情聚合状态、版本、关联关系、指标、告警和审计时间线。
- 价格/路由采用草稿、差异、仿真、审批、发布和回滚，不直接编辑 active 记录。
- 专享更换、未决重算和冲正使用向导，展示影响、二次认证、确认和结果。
- 用户会话可强制撤销；Connection 只显示指纹/能力/健康，不提供明文凭据入口。

## 边界与异常

后台不是数据库通用编辑器；不存在任意 SQL、任意字段 patch、删除账本/审计和设置最终余额功能。

## 验收标准

1. 各运营域关键读写流程均有 E2E 和 RBAC 负向测试。
2. 10 万级列表使用服务端分页，首屏 p95 ≤2 秒且无全表数据下发浏览器。
3. 所有配置发布前显示语义差异和仿真/校验结果，失败不改变 active version。
4. 高风险向导取消/超时不产生半完成状态，成功结果可按 request ID 追踪。
5. 页面源码、网络响应和导出中无明文凭据或不应见的个人数据。
6. 局部服务失败时页面明确标识未知/过期，不把旧数据显示为实时健康。

## 验收证据

后台 E2E、权限矩阵、性能记录、数据泄漏检查、配置发布/回滚和失败恢复测试。
