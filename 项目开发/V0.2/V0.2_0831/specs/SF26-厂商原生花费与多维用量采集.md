# SF26 厂商原生花费与多维用量采集

**优先级：** P0　**依赖：** SF04、SF19、SF20、SF21、SF22

## 功能描述

从三厂商原生响应、流事件和异步资源结果中采集货币花费与多维 usage，保留来源和证据，为同步或异步结算选择可信基础成本。

## 功能要求

- 按 Endpoint Catalog 定义每个端点可出现的 cost/usage 字段、单位、币种、时机和解析器版本。
- 优先采集 upstream 明确返回的可验证货币花费；否则采集 input/output/cache/reasoning/image/audio/time 等适用维度。
- streaming 在结束事件、headers 或异步查询中补全 usage；客户端提前断开仍尝试获得可用证据。
- 原始值、标准化值、source、parser version、完整性和证据摘要同时保存。
- 同时存在金额和 usage 时保留两者并计算差异，不以 computed 覆盖 reported。

## 边界与异常

不得假定所有 API 都按 token 计费。无金额且无适用 usage/rate 时标记 unresolved；解析失败不能变成 0。

## 验收标准

1. 目录每个 stable 端点都有明确 reported/computed/unresolved 计量策略。
2. 三厂商普通、流式、工具、文件/异步等适用 fixture 解析值与原生响应一致。
3. 金额与 usage 共存时金额被选为结算输入，差异指标可查询。
4. 缺失、未知单位、溢出、负数和解析器异常均进入明确错误/未决状态。
5. 重放同一原始证据得到同一标准化结果，旧 parser version 可重现。
6. 日志和事件不保存不必要的请求/响应正文或敏感文件内容。

## 验收证据

计量字段矩阵、解析 fixture、差异报告、异常测试和重放结果。
