# SF25 专享绑定、降级与人工更换

**优先级：** P0　**依赖：** SF11、SF15、SF16、SF22

## 功能描述

为 dedicated Project 的每个启用协议绑定一条独占 Connection。连接异常时进入 degraded 并关闭失败，绝不自动切换到共享池或其他连接；只有买家确认后管理员/授权流程才能人工更换。

## 功能要求

- 绑定事务保证 Connection 空闲、dedicated 模式、协议能力和价格有效；成功后独占。
- 所有请求（包括后续资源操作）固定到绑定 Connection；健康失败返回专享不可用错误。
- 更换流程展示影响：upstream 文件、batch、cache、fine-tuning、operation 等资源不会迁移。
- 更换要求买家显式确认、操作者权限、原因和 step-up；新连接复验后原子切换新请求。
- 旧连接进入 draining，处理允许完成的在途请求和历史资源查询策略；不得被立即共享复用。

## 边界与异常

无自动故障转移，无 shared fallback，无跨 Connection 资源复制。买家不确认时保持 degraded。

## 验收标准

1. 单个 Connection 不能并发绑定两个 Project/protocol。
2. 绑定连接 unhealthy 后 100% 新请求失败关闭，其他连接调用次数为 0。
3. 更换前 UI/API 明确列出不迁移资源并记录买家确认。
4. 原子切换期间请求只命中完整旧或新绑定，不出现随机混用。
5. 旧资源操作按既定策略命中旧连接或返回明确不可用，不误送新连接。
6. 更换全流程含 actor、buyer confirmation、原因、前后连接和时间审计。

## 验收证据

独占并发测试、故障关闭测试、资源不迁移 E2E、原子切换和审计记录。
