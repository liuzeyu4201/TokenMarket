# SF15 连接验证、能力发现与健康状态

**优先级：** P0　**依赖：** SF01、SF14

## 功能描述

在不暴露凭据的前提下验证 Provider Connection，发现其可用协议、模型、端点、区域和配额提示，并持续维护可解释的健康状态供上架与路由使用。

## 功能要求

- 创建/更新后执行鉴权、最小安全调用和能力发现；区分无效凭据、无权限、区域错误、限流和厂商故障。
- 能力结果与 Endpoint Catalog 交集形成 connection capability snapshot，并版本化保留。
- 主动探测与真实流量被动信号共同计算 healthy、degraded、unhealthy、unknown；带原因和时间。
- 探测具有抖动、退避和全局预算，不能形成 upstream 压力或产生不可控费用。
- 卖家看到可操作的脱敏诊断；路由读取统一健康快照。

## 边界与异常

能力发现不能保证厂商未来始终可用；未知能力默认不可路由。探测不得创建难以清理的文件、批任务或调优任务。

## 验收标准

1. 三厂商合法/非法/权限不足/区域错误凭据均得到可区分状态。
2. capability snapshot 只包含目录内且已验证能力，旧快照可追踪。
3. 连续成功/失败按配置阈值转换状态，无单次抖动频繁上下架。
4. 1000 连接探测调度遵守并发和费用预算，无同步风暴。
5. 凭据错误修复后可手动立即复验，状态在目标时间内恢复。
6. 卖家诊断和系统日志均不泄露 secret 或完整敏感 upstream 响应。

## 验收证据

厂商验证夹具、状态机测试、探测负载报告、快照样例和脱敏审计。
