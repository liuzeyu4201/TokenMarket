# SF16 共享/专享供给模式与连接生命周期

**优先级：** P0　**依赖：** SF14、SF15

## 功能描述

卖家将 Connection 选择为共享池供给或专享候选供给。一个 Connection 同一时刻只能属于一种模式；处于活动绑定、在途任务或未结算状态时不可切换模式或删除。

## 功能要求

- 生命周期至少为 draft、verified、listed、reserved/bound、paused、draining、retired。
- 模式在上架时确定；切换需先下架、排空、完成结算与解除所有绑定。
- shared 连接可被多个买家动态选择；dedicated 连接只能绑定一个 Project+protocol。
- 暂停立即阻止新请求，排空允许在途请求/资源生命周期按策略完成。
- 删除前返回依赖清单，历史记录保留不可变 Connection ID 和卖家归属。

## 边界与异常

专享连接不能借给共享池填补空闲容量；共享连接不能临时充当专享故障回退。

## 验收标准

1. 状态/模式转换矩阵的合法与非法路径 100% 有测试。
2. 并发上架、绑定、切换时数据库约束保证一个 Connection 一个模式/绑定。
3. active/unsettled 连接切换或删除返回具体阻塞原因。
4. pause 在 1 秒内阻止新路由；drain 不强制改道已建立资源亲和。
5. dedicated 连接在任何共享路由模拟中均不可见，反向亦然。
6. retired 后历史账务和审计仍能解析 Connection 元数据。

## 验收证据

状态机/数据库并发测试、暂停传播、路由隔离属性测试和历史查询样例。
