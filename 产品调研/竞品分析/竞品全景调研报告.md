# 竞品全景调研报告：TokenScavenger 竞争格局分析

> **调研日期**：2026-07-11  
> **调研范围**：直接竞品、间接竞品（API网关、算力共享、礼品卡市场、SaaS管理、闲置资源变现）、国内竞品生态  
> **核心问题**：市面上是否有同类型竞品？我们的差异化空间在哪里？

---

## 一、核心发现：竞争格局全景

### 1.1 竞争矩阵总览

| 竞争维度 | 代表竞品 | 竞争强度 | 核心威胁 | 与我们的关系 |
|---------|---------|---------|---------|------------|
| **直接竞品：专业额度转售** | AI Credits, CreditSwap | ⭐⭐⭐⭐⭐ | 模式已验证，直接解决相同痛点 | 国际B2B大额，我们做C2C小额碎片化 |
| **直接竞品：灰色中转站** | 88code, PoloAPI, 4SAPI等 | ⭐⭐⭐⭐ | 价格低、用户基数大、运营灵活 | 无平台信任机制，我们提供合规+信任 |
| **间接竞品：API聚合网关** | OpenRouter, OneAPI, LiteLLM | ⭐⭐⭐ | 统一入口、品牌强、技术成熟 | 解决"接入"问题，不解决"浪费"问题 |
| **间接竞品：国内聚合平台** | 硅基流动、阿里云百炼、腾讯云混元 | ⭐⭐⭐⭐ | 巨头生态，定价权强 | 做B2C转售，不做C2C撮合 |
| **间接竞品：算力共享** | Vast.ai, RunPod, 无问芯穹 | ⭐⭐ | 解决相似成本问题，形态不同 | GPU算力 vs API Token，不同资产类别 |
| **间接竞品：礼品卡二手市场** | Raise.com, CardCash | ⭐⭐ | 模式验证（C2C预付资产交易） | 不同品类，但信任机制可参考 |
| **间接竞品：AI成本管理SaaS** | Helicone, Langfuse, CloudZero | ⭐⭐⭐ | 解决"可见性"问题，不解决"交易"问题 | 工具 vs 市场，可互补 |
| **间接竞品：SaaS管理平台** | Zylo, CloudEagle, Torii | ⭐⭐ | 管理应用层席位，不管理资源层额度 | 完全不重叠，可集成 |
| **间接竞品：闲置资源变现** | 网心云, Honeygain, Storj | ⭐⭐⭐ | 验证C端"闲置变现"需求真实存在 | 物理资源 vs 数字资源，用户教育逻辑可借鉴 |
| **开源基础设施** | NewAPI, OneAPI, LiteLLM | ⭐⭐⭐ | 降低准入门槛，可被快速复制 | 我们的技术基础，但需做差异化层 |

### 1.2 最关键的四个结论

1. **直接C2C额度交易市场：全球空白**
   - AI Credits（国际）和CreditSwap（国际）做B2B大额账户/凭证转移
   - 国内大量灰色中转站做B2C平台→用户单向转售
   - **但没有任何平台支持用户之间自由买卖、转让、共享AI API额度**

2. **API聚合网关极其拥挤，但解决的是"接入"而非"浪费"**
   - OpenRouter 500万+用户、$13亿估值、年化$1亿+交易额
   - 但它是"官方一级渠道聚合"，不是"二手额度撮合"
   - 它是"帮你用一个Key调多个模型"，不是"帮你把用不完的额度卖给别人"

3. **灰色市场庞大但脆弱，是机会也是警示**
   - 国内88code、PoloAPI、4SAPI、laozhang.ai等数量众多
   - 基于开源NewAPI/OneAPI快速搭建，价格低至官方10%
   - 但无信任机制、无平台保障、随时被封，用户投诉无门

4. **用户教育已被验证："闲置变现"是真实需求**
   - 网心云（闲置带宽）、Honeygain（全球1000万+用户）、Raise.com（礼品卡$50亿交易额）
   - 证明C端用户愿意为"闲置资源变现"安装工具/使用平台
   - 但API Token是数字资产，比带宽/存储更即时、更易交易

## 二、直接竞品深度分析

### 2.1 AI Credits (aicredits.co) — 最直接的海外对标

| 维度 | 详情 |
|------|------|
| **网址** | aicredits.co |
| **模式** | B2B大额AI API额度交易市场 |
| **交易额** | $20M+ |
| **买家数** | 200+ |
| **覆盖平台** | OpenAI, Anthropic, Google, AWS, Azure等20+ |
| **卖家回收** | 面值的40-70% |
| **买家折扣** | 零售价的40-80%（省20-60%） |
| **最低交易** | $500+（小额不划算） |
| **交易机制** | Escrow保护、双方验证、NDA、税务文档、发票 |
| **核心差异** | ① 做B2B大额，不做C2C小额；② 做一次性账户/凭证转移，不做持续代理共享；③ 偏正式商务流程，非技术驱动 |

**我们的机会**：做C2C小额碎片化、技术驱动（代理转发不暴露Key）、更轻量更即时

---

### 2.2 CreditSwap (creditswap.app) — 技术最相近的海外对标

| 维度 | 详情 |
|------|------|
| **网址** | creditswap.app |
| **模式** | 浏览器扩展 + 市场平台（Private Beta） |
| **核心机制** | 卖家本地保留Key，扩展自动接收/执行请求，Key永不出本机 |
| **卖家回收** | 70%当前零售价值 |
| **买家折扣** | 比零售低20% |
| **覆盖平台** | OpenAI, Anthropic（当前launch providers） |
| **合作伙伴** | 12个Trusted private beta partners |

**我们的机会**：CreditSwap是浏览器扩展模式（客户端代理），我们可以做**云端代理**（更稳定、更高并发、更易管理）+ **多平台覆盖**（不只做OpenAI/Anthropic）+ **积分体系**（非一次性交易）

---

### 2.3 国内灰色中转站生态 — 最大的竞争威胁也是最大的市场验证

| 代表平台 | 特点 | 价格水平 | 风险 |
|---------|------|---------|------|
| **4SAPI** | 485+模型，支持OpenAI/Claude/Gemini等 | 官方10-30% | 随时被封，无保障 |
| **EasyRouter (傅盛)** | 猎豹移动背景，国内节点 | 官方20-40% | 企业级但非C2C |
| **88code / PoloAPI** | 大量小站，基于NewAPI搭建 | 官方10-20% | 最不稳定 |
| **laozhang.ai** | 个人运营，Telegram/微信小程序销售 | 官方15-25% | 无平台信任 |
| **AnyRouter / 问问Code** | 新兴小站，快速复制 | 官方10-30% | 同质化严重 |

**核心洞察**：这些平台**全部是B2C"批发零售"模式**——平台自己批量采购（或破解/共享账号）→加价卖给用户。没有一个是**C2C用户之间自由交易**。

**这恰恰是我们的核心差异化**：我们不是"平台卖给你"，而是"张三卖给你，我们撮合并担保"。

## 三、间接竞品分析

### 3.1 API聚合网关：OpenRouter

| 维度 | 详情 |
|------|------|
| **用户量** | 500万+开发者 |
| **年化交易额** | $1亿+ |
| **估值** | $13亿 |
| **模式** | 统一API入口，按量计费+5.5%手续费 |
| **是否加价** | 否，pass-through定价 |
| **是否解决浪费** | 否，帮用户"接入"，不帮用户"卖出剩余" |

**与我们的关系**：OpenRouter是"一级市场"（官方渠道聚合），我们是"二级市场"（用户剩余额度撮合）。两者可以互补——我们的平台可以集成OpenRouter作为底层路由之一。

---

### 3.2 开源基础设施：OneAPI / NewAPI / LiteLLM

| 项目 | GitHub Stars | 核心功能 | 与我们的关系 |
|------|-------------|---------|------------|
| **OneAPI** | 28,000+ | 多模型适配、Key管理、倍率加价 | 我们的技术基础，可基于此二次开发 |
| **NewAPI** | 14,000+ | 基于OneAPI，支持40+提供商、配额管理 | 国内灰色中转站的主要底层技术 |
| **LiteLLM** | 32,000+ | 多模型路由、成本追踪、预算控制 | 企业级开源，功能更全 |

**核心洞察**：开源项目降低了"自建中转站"的技术门槛到几乎为零。但**开源解决的是"技术实现"，不解决"市场撮合""信任机制""用户增长"**。这正是我们的竞争壁垒所在。

---

### 3.3 国内正规军：硅基流动、阿里云百炼、腾讯云混元

| 平台 | 定位 | 用户规模 | 模式 |
|------|------|---------|------|
| **硅基流动 (SiliconFlow)** | 独立MaaS | 1000万+用户，$77.4亿估值 | 平台批量采购→按量加价卖给用户 |
| **阿里云百炼** | 大厂生态 | 庞大 | 自研+第三方模型聚合，企业SaaS |
| **腾讯云混元** | 大厂生态 | 庞大 | 自有模型+第三方，微信生态集成 |
| **字节火山引擎** | 大厂生态 | 庞大 | 豆包模型+第三方，字节生态集成 |

**与我们的关系**：这些平台是"一级市场批发商"，我们是"二级市场撮合平台"。它们赚取的是"采购价→零售价"的差价，我们赚取的是"用户间撮合+信任担保"的服务费。两者可以共存——甚至我们的平台可以帮用户接入这些一级平台，再撮合剩余额度。

---

### 3.4 算力共享：Vast.ai / RunPod / 无问芯穹

| 平台 | 模式 | 规模 | 差异点 |
|------|------|------|--------|
| **Vast.ai** | P2P GPU市场 | 20,000+ GPU，700K月交易 | 物理GPU算力，非API Token |
| **RunPod** | 混合云GPU | 1M+开发者，31区域 | 自营+社区竞价，算力非额度 |
| **无问芯穹** | B2B异构算力调度 | 融资22亿+，25000P算力 | 企业级重基础设施，不面向个人 |
| **AWS Spot** | 云内部二级市场 | 折扣50-90%，成熟生态 | 单一供应商内部，非跨平台 |

**核心洞察**：算力共享（GPU/VM）的P2P市场已被验证（Vast.ai非常活跃），但**API Token的P2P交易市场完全空白**。两者的资产形态不同：GPU是物理资源，需要持续在线；API Token是数字资源，可以即时交易、即时清算。

---

### 3.5 礼品卡二手市场：Raise.com / CardCash

| 平台 | 模式 | 规模 | 关键机制 |
|------|------|------|---------|
| **Raise.com** | C2C礼品卡市场 | 2M+用户，$50亿+交易额，$1.47亿+融资 | 15%佣金，1年退款保证 |
| **CardCash** | B2C2C做市商 | 500+品牌，2023年被收购 | 平台买断再转售，45天保障 |

**核心洞察**：礼品卡是"预付资产的二级市场"，与API额度本质相同。Raise.com验证了**C2C预付资产交易的市场需求真实存在**，且可以做大（$50亿交易额）。但礼品卡是**合法转售**（商家不禁止），API额度是**灰色地带**（平台ToS禁止）。这是关键差异，也是我们的核心风险。

---

### 3.6 AI成本管理SaaS：Helicone / Langfuse / CloudZero

| 工具 | 核心功能 | 是否解决浪费 | 模式 |
|------|---------|-------------|------|
| **Helicone** | LLM可观测性+Gateway | 缓存节省20-30%，但无硬预算拦截 | 开源+SaaS |
| **Langfuse** | 开源LLM工程平台 | 成本归因优秀，但无预算执行 | 开源+SaaS |
| **CloudZero** | 云成本智能 | 报告浪费，自动化有限 | 企业SaaS |
| **9Router** | 本地AI路由+省钱工具 | 多账户轮换，个人级 | 纯开源 |
| **OmniRoute** | 增强版AI Gateway | 功能更强，但无企业管控 | 纯开源 |

**核心洞察**：这些工具都是"望远镜"（帮你看见浪费），我们是"刹车+导航"（帮你阻止浪费+把浪费变现）。**两者可以互补**——我们的平台可以集成这些工具作为"成本监控"层，帮助用户更智能地决定"什么时候卖出、什么时候买入"。

---

### 3.7 闲置资源变现：网心云 / Honeygain / Storj

| 平台 | 资源类型 | 用户规模 | 核心教育逻辑 |
|------|---------|---------|-------------|
| **网心云** | 闲置带宽 | 非常活跃，迅雷背书 | "躺赚，覆盖网费" |
| **Honeygain** | 闲置带宽 | 1000万+用户，全球领导者 | "被动收入，无需操作" |
| **Storj** | 去中心化存储 | 8000+节点 | Token激励 |
| **Filecoin** | 去中心化存储 | 15EiB容量 | 挖矿激励 |

**核心洞察**：这些平台验证了**C端用户愿意为"闲置资源变现"使用平台**。核心用户教育逻辑是："你已经付了钱，不用白不用，挂上去就能赚"。这与我们的API额度场景完全一致。但API Token的优势在于：**不需要持续在线、不需要硬件、不需要带宽，交易即时完成**。

## 四、竞品空白分析：我们的机会在哪里？

### 4.1 已验证的市场（有竞品，但我们可以做得更好）

| 市场 | 竞品 | 空白/不足 | 我们的机会 |
|------|------|----------|-----------|
| **B2C Token转售** | 4SAPI, EasyRouter, 灰色小站 | 无信任机制、无平台保障、随时被封 | 合规+信任+担保 |
| **B2B大额额度交易** | AI Credits | 只做大额($500+)、流程重、技术轻 | 小额碎片化、技术驱动、即时交易 |
| **API聚合接入** | OpenRouter, 硅基流动 | 只解决"接入"，不解决"浪费" | 在接入之上加"交易层" |
| **成本监控** | Helicone, Langfuse | 只监控不交易 | 监控+交易一体化 |

### 4.2 完全空白的市场（无竞品，需验证需求）

| 市场 | 空白描述 | 风险 |
|------|---------|------|
| **C2C额度交易市场** | 用户之间自由买卖API额度 | 需求是否足够大？信任机制能否建立？ |
| **拼单/团购模式** | 多人合买一个套餐共享额度 | 平台方封禁风险、账户共享合规问题 |
| **企业剩余额度回收** | 帮助大企业盘活闲置API席位 | 企业决策流程长、需要销售团队 |
| **积分/代币体系** | 用"平台积分"替代现金交易 | 金融合规风险、用户接受度 |
| **Coding Plan额度交易** | 专门针对编程助手的订阅额度 | 技术接入难度（IDE插件 vs API Key） |

### 4.3 已验证但失败的市场（警示）

| 产品 | 失败原因 | 教训 |
|------|---------|------|
| **Oneloop** | 2025年9月关闭，纯API Key管理工具，无市场流动性 | 纯工具无市场难以存活，必须做交易撮合 |
| **Gift Card Granny** | BBB F级评级，25万+投诉，信任危机 | 聚合器模式（不直接交易）无法建立信任，必须做 escrow/担保 |
| **大量灰色小站** | 频繁被封，用户流失 | 无合规=无可持续性 |

## 五、差异化定位建议

基于竞品分析，我们提出**三层差异化定位**：

### 第一层：C2C小额即时交易（MVP阶段）

> **口号**："用不完的AI额度，秒变现金；想用的AI模型，半价体验"

- **对标**：填补AI Credits（B2B大额）和灰色小站（B2C无信任）之间的空白
- **核心功能**：一键挂售剩余额度、一键购买折扣额度、平台 escrow 担保、按量计费
- **目标用户**：个人开发者、学生、自由职业者
- **竞争壁垒**：信任机制（escrow+评价+保险）+ 即时交易（技术代理）+ 多平台覆盖

### 第二层：企业额度管理SaaS（Plan B）

> **口号**："AI支出可视化、可控化、可优化"

- **对标**：比Helicone/Langfuse多"交易层"，比Zylo/CloudEagle多"API资源层"
- **核心功能**：多平台额度聚合、实时监控、自动预警、剩余额度自动挂售、内部池化管理
- **目标用户**：中小企业、AI-first初创公司
- **竞争壁垒**：数据积累（使用模式、价格趋势）+ 工作流集成（CI/CD、IDE、Slack）

### 第三层：AI算力银行（长期愿景）

> **口号**："AI算力的活期储蓄和借贷"

- **对标**：比Vast.ai（GPU）更轻量，比Raise.com（礼品卡）更即时，比OpenRouter（接入）更增值
- **核心功能**：积分体系、时间错配、规模聚合、智能定价、跨平台套利
- **目标用户**：全生态
- **竞争壁垒**：网络效应（卖家越多→买家越便宜→买家越多→卖家越好卖）+ 数据智能（最优定价、最优路由）

## 七、结论

### 7.1 竞争格局总结

| 问题 | 结论 |
|------|------|
| 是否有直接同类型竞品？ | **没有完全相同的C2C额度交易平台**。AI Credits和CreditSwap最接近，但做B2B/技术代理，不做C2C小额撮合。 |
| 是否有间接替代品？ | **很多**。API聚合网关、灰色中转站、成本管理工具都可以部分替代我们的功能。但它们不解决"撮合交易"这个核心问题。 |
| 市场是否被验证？ | **是**。B2C Token转售（灰色市场极其活跃）、礼品卡二手市场（$50亿+）、闲置带宽变现（1000万+用户）都验证了"预付资产二级市场"的需求。 |
| 我们的窗口期多长？ | **6-12个月**。平台方正在推出企业池化（阿里云百炼已做），个人池化可能跟进。但C2C交易市场被ToS禁止，大厂不会自己做。 |
