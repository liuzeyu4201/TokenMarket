# SF03 分布式认证、路由状态与容量协调

**优先级：** P0　**依赖：** SF01、SF02

## 功能描述

提供跨节点一致的短期认证状态、限流、容量租约、连接占用和资源亲和解析，保证多 Gateway 并发下不会突破配额、重复占用专享连接或把有状态资源送往错误连接。

## 功能要求

- PostgreSQL 保存权威配置与绑定；Redis 保存带 TTL、可重建的热状态。
- 限流和容量预占采用原子操作，维度至少含 Key、Project、Connection 和协议。
- 专享连接占用使用数据库唯一约束；亲和映射持久化并带生命周期状态。
- 缓存失效通过版本/事件传播；权限撤销和 Key 禁用在 1 秒内对所有节点生效。
- Redis 数据丢失后从事实源安全重建；无法判断时不得扩大权限或容量。

## 边界与异常

Redis 不是余额、账本、用户或 Provider Binding 的事实源。网络分区时优先防止越权与超卖，可以降低可用性。

## 验收标准

1. 20 个并发客户端争抢单个专享连接时只有一个成功绑定。
2. 多节点总流量不超过配置容量误差 1%，不会按实例各放行一份配额。
3. Key 撤销后 1 秒内所有 Gateway 拒绝新请求。
4. Redis 清空并恢复后，权限、绑定和亲和映射无越权；必要映射可从数据库重建。
5. 重复释放、租约超时和客户端断连不会产生负容量或永久占用。
6. 跨租户随机并发测试未发现状态串用。

## 验收证据

原子脚本/事务测试、并发争抢报告、Redis 故障注入、撤销传播计时和租户隔离测试。
