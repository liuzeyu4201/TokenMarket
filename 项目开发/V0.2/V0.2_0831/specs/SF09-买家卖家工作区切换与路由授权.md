# SF09 买家/卖家工作区切换与路由授权

**优先级：** P0　**依赖：** SF07、SF08

## 功能描述

为 buyer、seller、both 三类角色提供清晰的工作区边界。双角色用户可以显式切换买家/卖家工作区，但数据查询、操作权限和默认导航必须随工作区一起切换，并在服务端强制校验。

## 功能要求

- 会话保存当前工作区，但权限来自账户角色；切换动作不能提升未授予角色。
- 买家查询只返回其 Projects、Keys、用量和扣减；卖家查询只返回其 Connections、报价、健康和测试收益。
- 每个写操作同时校验 actor、workspace、resource ownership 和具体 action。
- 双角色用户的连接不得路由给其本人拥有的 Project，路由层按不可伪造 owner ID 排除。
- 工作区切换清除前一工作区缓存、筛选条件和敏感页面状态。

## 边界与异常

UI 切换不是安全边界；直接调用另一工作区 API 必须返回 403。管理员身份不通过普通工作区获得。

## 验收标准

1. 三类角色的导航和 API 权限矩阵全部有正向与负向测试。
2. 修改客户端 workspace 参数不能读取或操作另一角色/租户资源。
3. 切换后页面缓存、URL 和后台请求均只属于新工作区。
4. buyer-only/seller-only 用户尝试切换未授权工作区得到 403 且有审计。
5. 10 万次模拟共享路由中，自有 Project 从未选中自有 Connection。
6. 双角色并发打开两个工作区标签页不会发生服务端权限串用。

## 验收证据

角色动作矩阵、API 越权测试、浏览器多标签 E2E、自路由属性测试和审计记录。
