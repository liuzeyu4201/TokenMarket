# SF02 代理网关无状态化与水平扩展

**优先级：** P0　**依赖：** SF01

## 功能描述

把 Go Proxy Gateway 建成唯一公网模型入口和可水平扩展的无状态数据面。任一请求可由任一健康节点处理，节点终止不丢失授权、路由、计量或账务事实。

## 功能要求

- 本地内存只保存可重建缓存，不保存唯一会话、额度、路由占用或用量事件。
- 统一执行 request ID、Project/Key 鉴权、协议识别、请求限制、路由调用、响应流转和用量事件生成。
- 配置和目录按不可变版本加载并原子切换；在途请求继续使用进入时锁定版本。
- readiness 检查必要依赖与目录版本，liveness 不因短暂 upstream 故障误杀进程。
- 支持优雅摘流、在途非流式完成和长连接有界排空。

## 边界与异常

Gateway 不承载用户管理、价格编辑或人工账务操作；共享依赖不可用且无法安全判定权限/路由时失败关闭，不凭缓存猜测。

## 验收标准

1. 至少 3 个 Gateway 实例下，同一合法 Key 的请求可随机分配且行为一致。
2. 压测中逐个终止实例，非流式失败率不超过 0.1%，无重复账务事件。
3. 重启全部 Gateway 后无需恢复本地文件即可继续处理已存在 Project。
4. 配置切换并发测试证明每个请求仅使用一个完整版本，无混合字段。
5. 摘流后不接收新请求；在途请求按设定期限完成或返回确定错误。
6. Gateway 日志和指标不包含 upstream 密钥、验证码、完整请求正文或敏感响应。

## 验收证据

多实例拓扑、节点终止测试、配置原子切换测试、日志脱敏扫描、容量基准和资源曲线。
