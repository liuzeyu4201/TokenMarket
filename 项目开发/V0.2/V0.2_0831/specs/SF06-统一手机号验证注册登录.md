# SF06 统一手机号验证注册登录

**优先级：** P0　**依赖：** V0.1 用户与认证

## 功能描述

提供一个手机号验证码入口，同时完成已有用户登录和新用户注册。验证前不暴露手机号是否注册；新用户验证后补充昵称和角色并自动进入平台。

## 功能要求

- 发送验证码接口始终返回一致的可接受响应，应用层不泄露账号存在性。
- 验证码单次有效、短时过期、限制尝试次数，并按手机号、设备/IP 和全局维度限流。
- 已有用户验证成功直接创建会话；新用户进入资料补全，昵称和角色保存成功后原子创建账号与会话。
- 角色支持 buyer、seller、both；手机号规范化和唯一性由数据库约束保证。
- 短信供应商失败、延迟与重试有明确 UI 状态和审计，但日志不记录验证码。

## 边界与异常

不实现密码登录、第三方 OAuth 或企业 SSO。不得通过响应时间、状态码、错误文案和重试额度明显枚举账号。

## 验收标准

1. 已注册/未注册手机号发送验证码的状态码、响应结构和文案相同。
2. 正确、错误、过期、已使用验证码均有自动化测试；验证码不能重放。
3. 50 个并发注册同一手机号只产生一个账号。
4. 新用户完成资料后自动登录；中断后可安全恢复而不产生半账号。
5. 限流测试覆盖手机号/IP/设备，合法用户在冷却期后可重试。
6. 日志、trace、错误平台和数据库普通字段均无明文验证码。

## 验收证据

API/数据库并发测试、反枚举时延抽样、短信故障测试、UI E2E 和秘密扫描。
