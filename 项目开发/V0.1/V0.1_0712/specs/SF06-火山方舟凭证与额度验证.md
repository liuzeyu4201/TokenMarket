# Feature Specification: SF06 火山方舟凭证与额度验证

**Feature ID**: `SF06`  
**Short Name**: `volcano-key-validation`  
**Created**: 2026-07-13  
**Status**: Draft  
**Source**: 周度 Spec F03/F05、PRD Key 接入、Go 平台适配器规范

## 目标与价值

为系统内部提供火山方舟凭证验证能力，在持久化或投入路由池之前确认凭证的认证状态、权限、剩余额度和可用模型。验证结果必须区分永久无效、零额度、限流和临时故障，防止把可恢复故障误判成永久失效。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 验证有效凭证和额度 (Priority: P1)

作为准备接入 Key 的卖家，我希望平台快速确认凭证有效并展示真实剩余额度，以便知道它是否可用于 V0.1 代理服务。

**Independent Test**: 使用火山方舟测试环境或受控契约替身返回有效凭证、额度和模型，验证标准化结果。

**Acceptance Scenarios**:

1. **Given** 凭证有效、具备所需权限且余额大于零，**When** 发起验证，**Then** 3 秒内返回 valid、可用额度、支持模型和验证时间。
2. **Given** 凭证有效但额度为零，**When** 发起验证，**Then** 返回“凭证有效但不可路由”的零额度结果，而不是认证失败。
3. **Given** 上游返回可用模型列表，**When** 标准化结果，**Then** 只标记 V0.1 支持的 Chat Completions 模型能力。

---

### User Story 2 - 获得稳定且安全的失败分类 (Priority: P1)

作为 Key 接入和健康检查能力，我希望根据失败类型采取不同状态转换，而不是依赖上游错误文本。

**Independent Test**: 模拟 401、403、429、超时、连接失败、格式错误和 5xx，验证错误分类和是否允许重试。

**Acceptance Scenarios**:

1. **Given** 上游返回 401 或 403，**When** 验证凭证，**Then** 返回永久认证/权限失败分类，不返回或记录完整凭证。
2. **Given** 上游返回 429，**When** 验证凭证，**Then** 返回 rate_limited 和建议重试时间，不标记凭证永久无效。
3. **Given** 上游超时、网络失败或 5xx，**When** 验证凭证，**Then** 返回暂时不可用分类，不声称余额为零或凭证无效。
4. **Given** 上游响应无法解析，**When** 验证，**Then** 返回上游协议错误并保留安全诊断信息。

### Edge Cases

- 上游在 3 秒截止前部分返回数据但响应未完成。
- 余额单位、精度或字段缺失，与已知契约不一致。
- 同一凭证被多个接入请求同时验证。
- 请求取消后上游调用仍未结束。
- 上游返回成功状态但认证信息或模型列表为空。
- 错误响应正文包含用户原始 Key 或其他敏感头。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 验证输入 MUST 只接受内部调用传入的火山方舟凭证和请求标识；V0.1 对其他平台返回 unsupported_platform。
- **FR-002**: 验证 MUST 检查认证有效性、必要权限、剩余额度和 V0.1 所需模型能力。
- **FR-003**: 正常验证 MUST 在 3 秒截止时间内返回；调用方取消时 MUST 立即传播取消。
- **FR-004**: 标准结果 MUST 至少包含 validity、availability、remaining_quota、quota_unit、supported_models、checked_at 和 error_category。
- **FR-005**: 401 与 403 MUST 映射为认证或权限的永久失败；429 MUST 映射为限流；超时、连接错误和 5xx MUST 映射为临时失败。
- **FR-006**: 零额度 MUST 与无效凭证区分，并标记为不可接入/不可路由。
- **FR-007**: 临时失败或限流 MUST NOT 覆盖最后一次可信的认证事实为“无效”。
- **FR-008**: 验证能力 MUST NOT 持久化完整凭证；是否保存标准化结果由 SF08/SF16 决定。
- **FR-009**: 完整凭证 MUST NOT 出现在响应、错误、日志、指标、追踪、测试快照或 panic 信息中。
- **FR-010**: 暴露给调用方的错误类别 MUST 稳定，不依赖火山方舟原始错误文案。
- **FR-011**: 上游响应字段与契约不符时 MUST 失败关闭，不得猜测余额或权限。

### Engineering Requirements *(mandatory)*

- **ER-001 — Contracts**: 验证结果与错误分类须形成版本化内部契约；计划阶段必须根据当期火山方舟官方文档确认端点和字段，并用契约测试固定。
- **ER-002 — Security & Privacy**: 原始 Key 只在受控内存中短暂存在，使用后尽快释放；认证头和响应正文先脱敏再进入诊断路径。
- **ER-003 — Data Integrity**: 额度使用整数基础单位或精确小数表示，必须携带单位和采集时间；不得使用二进制浮点表示价值或额度。
- **ER-004 — Performance & Capacity**: 单次验证硬截止 3 秒；并发验证必须有全局与单凭证上限，避免触发上游滥用保护。
- **ER-005 — Reliability**: 只对确认幂等且属于临时网络故障的读取进行有界重试；重试总时长不得突破 3 秒截止。
- **ER-006 — Observability**: 记录平台、结果类别、耗时、上游状态类别和请求标识；凭证仅可使用不可逆脱敏标识聚合。
- **ER-007 — Accessibility**: V0.1 无界面；错误分类和建议动作必须机器可读，便于未来界面区分修正凭证、补充额度和稍后重试。

### Failure and Recovery Scenarios *(mandatory)*

1. **Given** 火山方舟超时或 5xx，**When** 验证运行，**Then** 3 秒内结束为临时失败，不创建永久无效状态，调用方可按策略稍后重试。
2. **Given** 调用方取消请求，**When** 上游仍在处理，**Then** 取消传播到网络调用并释放连接与敏感内存。
3. **Given** 适配契约升级导致字段无法解析，**When** 验证响应到达，**Then** 标记协议错误、触发告警信号并阻止该结果进入路由池。

### Key Entities

- **Provider Credential Input**: 仅在一次验证期间存在的敏感输入；不得作为本功能持久实体。
- **Credential Validation Result**: 认证状态、可用性、精确额度、单位、模型、采集时间、错误类别和安全凭证指纹。
- **Provider Error Classification**: success、invalid、forbidden、zero_quota、rate_limited、temporary_unavailable、timeout、invalid_response。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 合同测试中的有效、401、403、429、零额度、超时、5xx 和非法响应分类准确率为 100%。
- **SC-002**: 95% 正常验证在 3 秒内完成，所有请求均在 3 秒硬截止内结束或被取消。
- **SC-003**: 有效凭证的额度与受控官方响应完全一致，不发生单位或精度丢失。
- **SC-004**: 临时失败和限流测试中，永久 invalid 状态写入次数为 0。
- **SC-005**: 日志、错误、追踪和测试输出扫描不出现任何完整火山方舟凭证。

## Scope

### In Scope

- 火山方舟凭证、余额、权限、模型验证及稳定错误分类。

### Out of Scope

- Key 持久化、加密、生命周期状态、代理转发、健康调度、多平台和官方余额扣减。

## Test Requirements

- 适配器单元测试使用受控 Mock 覆盖全部状态和格式边界。
- 契约测试固定当期官方响应字段、额度单位和错误映射。
- 集成测试仅使用合成或专用测试凭证，不得把真实凭证写入夹具。
- 超时、取消、连接泄漏和并发上限需要负面测试。
- Go 适配相关包至少 80% 行覆盖，错误分类和脱敏分支直接覆盖。

## Assumptions

- 依赖 SF01 的网关工程基线；不依赖账户或 Key 数据库。
- 火山方舟官方接口细节属于易变外部契约，实施计划必须用当期官方文档复核。
- SF08 使用本功能决定是否接入，SF16 使用本功能更新健康事实。
