# SF27 版本化费率、买家倍率与卖家报价

**优先级：** P0　**依赖：** SF01、SF26

## 功能描述

维护厂商 usage→基础成本费率、统一买家倍率、卖家受限报价倍率及其生效版本，确保请求时可锁定、历史可重算、平台价差永不为负。

## 功能要求

- 费率支持 provider/protocol/model/endpoint/usage dimension/region/currency 与有效时间。
- 买家倍率按平台策略统一呈现，可按明确范围版本化；卖家倍率必须处于平台上下界。
- 发布前检测覆盖空洞、重叠、单位冲突和负价差；通过草稿、预演、审批、发布。
- Gateway 在请求接受时锁定 rate、buyer multiplier、seller quote versions。
- 金额采用定点小数、明确舍入位置和精度；中间值保持高精度，最终分录统一舍入。

## 边界与异常

价格修改不追溯改变已接受请求。无适用费率不能临时猜价；进入 unresolved。普通卖家不可读取买家倍率内部策略。

## 验收标准

1. 边界值、极小/极大 usage、不同币种和舍入 golden tests 100% 通过。
2. 重叠/缺口/单位冲突/负价差版本无法发布。
3. 价格切换瞬间的并发请求分别使用明确旧/新完整版本。
4. 任意历史请求可用锁定版本重算出相同 buyer debit/seller earning/spread。
5. published 版本不可原地修改或删除，只能发布后续版本/回滚新版本。
6. 权限测试证明卖家和买家只能看到各自应见价格信息。

## 验收证据

费率 schema、精度测试、发布校验、并发切换、历史重算和权限报告。
