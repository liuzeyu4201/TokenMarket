## Clarifications

### Session 2026-08-31

已确认决策，未向用户重复提问：

- Q: 本 SF 是否实现买家/卖家业务操作？ → A: 否。只提供导航、反馈、权限呈现基础；未完成入口必须标明不可用，不得提交会失败的假操作或用静态假数据伪装已完成功能。
- Q: 工作区切换？ → A: 壳层展示当前角色工作区标识；切换交互留 SF09，本 SF 控件禁用并标明即将开放。
- Q: 通知是否接后端？ → A: 否。提供全局异步/离线/限流/错误状态区域；无消息中心后端。
- Q: 浏览器矩阵？ → A: 本 SF 交付可键盘操作、三视口无溢出与自动可访问性门禁。Chrome/Safari/Edge 实机矩阵由 SF34 补齐。
- Q: 无权限菜单？ → A: 可隐藏；不得暗示服务端会因此跳过鉴权。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 访客在公开站理解产品边界 (Priority: P1)

未登录访客打开首页，能看懂平台做原生三协议透传、共享/专享模式，以及只有测试额度、不可充值提现。

**Why this priority**: 公开站是 V0.2 对外说明与获客入口。

**Independent Test**: 打开首页可见上述边界说明；无买家/卖家业务表单提交。

**Acceptance Scenarios**:

1. **Given** 匿名访客，**When** 打开公开首页，**Then** 看到三协议原生透传、共享与专享、测试额度不可购买/转让/提现的说明。
2. **Given** 首页上的后续业务入口，**When** 访客尝试使用，**Then** 入口标明不可用，不会发出会失败的假请求。
3. **Given** 360、768、1440 视口，**When** 查看首页，**Then** 无阻断布局、无横向溢出。

---

### User Story 2 - 认证页与应用壳可完成导航 (Priority: P1)

访客完成登录后进入统一应用壳：全局导航、面包屑、工作区标识、账户安全、退出，以及加载/空/错误/禁止/限流/离线状态的一致呈现。

**Why this priority**: 后续所有业务页都挂在此壳上。

**Independent Test**: 已登录用户看到导航与工作区标识；键盘可到达主导航、主内容与退出；离线或限流有可见提示。

**Acceptance Scenarios**:

1. **Given** 已登录用户，**When** 查看壳层，**Then** 可见全局导航、当前位置面包屑、工作区标识、账户安全入口与退出。
2. **Given** 加载、空、部分失败、无权限、限流、离线任一状态，**When** 页面需要反馈，**Then** 使用统一状态组件，文案可感知且可键盘操作（重试等）。
3. **Given** 键盘用户，**When** 打开并关闭弹窗，**Then** 焦点进入弹窗并在关闭后回到触发控件。

---

### User Story 3 - 基础组件有完整可视状态 (Priority: P1)

表单、表格、弹窗、通知、错误边界等基础组件有文档化状态，页面不得各自再实现一套核心交互。

**Why this priority**: 防止后续 SF 复制私有按钮/弹窗导致无障碍与视觉漂移。

**Independent Test**: 组件目录覆盖默认/悬停/焦点/禁用/错误/加载；自动化交互测试通过。

**Acceptance Scenarios**:

1. **Given** 组件目录，**When** 查看每个核心组件，**Then** 至少包含默认、焦点、禁用与错误（如适用）状态。
2. **Given** 登录表单与工作台，**When** 检查实现，**Then** 使用共享表单/按钮/通知组件，而非第三套私有核心控件。
3. **Given** 渲染错误，**When** 子树抛出，**Then** 错误边界展示可恢复提示，不白屏。

---

### User Story 4 - 可访问与响应式不阻断 (Priority: P2)

桌面与移动关键视口可用；键盘可完成导航、表单和弹窗；自动扫描无严重问题。

**Why this priority**: WCAG 2.2 AA 是 V0.2 发布基线的一部分，本 SF 先把门禁做进壳层。

**Independent Test**: 360/768/1440 无横向溢出；焦点可见；自动扫描无 serious/critical。

**Acceptance Scenarios**:

1. **Given** 360、768、1440 视口，**When** 查看公开站、认证页、应用壳，**Then** 无横向溢出、无被遮挡的主操作。
2. **Given** 仅键盘，**When** 完成跳到主内容、导航、表单字段与弹窗，**Then** 焦点顺序合理且可见。
3. **Given** 自动可访问性扫描，**When** 扫描公开站、认证页、应用壳与组件目录，**Then** 无 serious/critical。

---

### Edge Cases

- 未完成业务入口必须禁用或说明即将开放，不得调用尚不存在的业务 API。
- 离线恢复后提示可消失或提供刷新，不得丢失已填写的认证表单（沿用现有挑战状态）。
- 无权限仅隐藏菜单不够：受保护路由仍须拒绝匿名。
- 不实现运营后台（SF31）与买家/卖家工作区切换（SF09）。

## Requirements *(mandatory)*

- **FR-001**: 必须提供颜色、排版、间距、状态与交互的共享视觉 token。
- **FR-002**: 必须提供共享的表单、表格、弹窗、通知、错误边界组件及其可视状态。
- **FR-003**: 公开站必须说明三协议原生透传、共享/专享模式与测试额度边界。
- **FR-004**: 应用壳必须提供全局导航、面包屑、工作区标识、账户安全入口与全局异步状态。
- **FR-005**: 页面必须能统一呈现 loading、empty、partial error、forbidden、rate limited、offline。
- **FR-006**: 360、768、1440 视口下公开站、认证页、应用壳不得横向溢出或阻断主操作。
- **FR-007**: 键盘必须能完成导航、表单与弹窗；弹窗关闭后焦点恢复。
- **FR-008**: 自动可访问性扫描不得出现 serious/critical。
- **FR-009**: 未完成业务入口必须标明不可用，不得提交假操作。
- **FR-010**: 不得用静态假业务数据伪装已完成的买家/卖家能力。

### Engineering Requirements

- **ER-001 — Contracts**: 组件与状态清单作为版本化 UI 契约，后续业务页必须复用而非分叉核心控件。
- **ER-002 — Security**: 无权限入口可隐藏，受保护路由仍须鉴权；不在前端展示会话 token。
- **ER-003 — Data**: 本 SF 不引入新的业务持久化；公开文案为静态产品边界，非账本数据。
- **ER-004 — Performance**: 首屏壳层与公开站在常规开发机上可交互，不引入阻塞大资源。
- **ER-005 — Reliability**: 离线与服务不可用有明确反馈与重试，不静默失败。
- **ER-006 — Observability**: 全局异步状态区域可被测试定位（loading/offline/error）。
- **ER-007 — Accessibility**: WCAG 2.2 AA 关键项：对比度、焦点、标签、键盘、跳过链接、语义地标。

### Failure and Recovery

1. **Given** 浏览器离线，**When** 用户仍停留在壳层，**Then** 显示离线状态且不提交假业务请求。
2. **Given** 子树渲染失败，**When** 错误边界捕获，**Then** 显示可恢复错误，其余导航仍可用。
3. **Given** 匿名访问受保护路径，**When** 打开工作台或账户安全，**Then** 转到登录，不展示受保护内容。

### Key Entities

- **DesignToken**: 颜色、字号、间距、焦点与状态色的共享命名。
- **FoundationComponent**: 按钮、表单字段、表格、弹窗、通知、错误边界、页面状态。
- **AppChrome**: 品牌、主导航、面包屑、工作区标识、账户安全、全局状态、主内容。
- **ProductBoundaryCopy**: 三协议、共享/专享、测试额度的公开说明。

## Success Criteria

- **SC-001**: 核心组件状态清单覆盖率 100%（默认/焦点/禁用/错误如适用），无第二套私有核心控件。
- **SC-002**: 公开站、认证页、应用壳在 360、768、1440 视口横向溢出次数 = 0。
- **SC-003**: 键盘可完成跳过链接、主导航、表单与弹窗开关；弹窗关闭后焦点回到触发器。
- **SC-004**: 自动可访问性扫描 serious/critical = 0。
- **SC-005**: 未完成业务入口可提交的假请求次数 = 0。
- **SC-006**: 公开站同时出现三协议、共享/专享、测试额度边界说明。

## Assumptions

- 复用已有 React 应用、登录/注册、应用壳与账户安全页。
- 实机 Chrome/Safari/Edge 矩阵与人工 AA 走查的完整证据在 SF34；本 SF 交付自动化门禁与组件目录。
- 工作区切换、买家 Project、卖家连接均尚未实现，只放不可用入口。
