# 第一章 执行摘要（Executive Summary）

## 1.1 项目定位与市场机遇

**TokenMarket** 是一家专注于 **AI Coding Plan 额度实时撮合** 的技术驱动型平台，致力于解决国内AI编程助手订阅市场中每年高达 **6–10亿元人民币** 的结构性浪费问题。

当前，国内主流AI编程平台——包括火山方舟Coding Plan、智谱GLM Coding Plan、阿里云百炼、MiniMax Coding Plan、Kimi Coding Plan以及国际上的Claude Code、GPT等——均采用"固定订阅+硬停止"的计费模式：用户按月支付订阅费（¥40–¥469不等），额度到期自动清零，不支持累积（No Rollover）、不支持暂停、不支持退款。据调研，国内Coding Plan付费开发者总数约 **50–80万人**，其中个人开发者的平均利用率仅为 **5%–15%**，企业闲置席位利用率低至 **5%** 左右，导致每年有价值约 **2–3亿元** 的有效剩余额度在月底被系统性清零，没有任何用户获得实际价值。

这一"结构性浪费"并非用户行为问题，而是平台商业模式的固有设计——所有主流Coding Plan平台均通过三层限流（5小时滚动窗口+每周限额+每月限额）和月底清零机制，将用户锁定在持续订阅的循环中。TokenMarket正是在这一市场空白中诞生，通过技术创新将分散的剩余额度聚合为可交易的数字资产，为卖家挽回成本、为买家降低门槛，同时构建可持续的平台经济。

## 1.2 核心痛点与解决方案

### 1.2.1 核心痛点

| 痛点维度 | 现状描述 | 数据来源 |
|---------|---------|---------|
| **额度浪费严重** | 个人开发者月利用率不足5%，企业闲置席位浪费率超95% | 《Coding Plan商业分析核心发现》 |
| **计费模式僵化** | 所有国内平台均采用"固定订阅+硬停止"，不支持rollover/暂停/退款 | 《Coding Plan商业分析核心发现》 |
| **买家门槛高企** | 优质Coding Plan月费¥149–¥200，预算受限用户难以持续订阅 | 《coding_plan_zhipu_glm.md》 |
| **灰色市场混乱** | 国内4SAPI、88code等灰色中转站价格低但无信任保障，随时面临封禁风险 | 《竞品全景调研报告》 |

### 1.2.2 解决方案

TokenMarket 创新性地构建了 **"C2C实时撮合+技术代理隔离"** 的双层架构：

- **卖家端**：额度剩余者（个人开发者、企业闲置席位管理员）将其API Key授权接入平台，设置挂售价格（通常为官方价的 **60%–75%**）和额度上限，平台通过技术手段实时隔离卖家原始Key，生成全新的平台Key供买家使用。

- **买家端**：额度需求者（预算受限开发者、临时项目需求者）按模型统一价（如官方价的 **80%–85%**）消费，无需绑定单一卖家。平台智能路由系统自动将请求分发至最优可用卖家Key，确保服务稳定性和响应速度。

- **结算机制**：平台按买家实际使用量结算，卖家按实际售出量×折扣价获得收益，平台赚取 **约15%的利差**。

- **核心原则**：平台不囤积任何额度，不承担过期风险，纯实时撮合——每一笔交易都在真实供需之间即时完成。

这一模式的关键优势在于，它既不同于灰色中转站的"平台自营批发"模式（B2C），也不同于AI Credits的"大额账户凭证转移"（B2B），而是开创了全球首个 **C2C（用户对用户）AI额度实时交易市场**。

## 1.3 目标市场与进入策略

TokenMarket 采用 **"先个人、后企业"** 的两阶段市场渗透策略：

| 阶段 | 目标用户 | 核心需求 | 市场路径 |
|------|---------|---------|---------|
| **第一阶段（MVP）** | 个人开发者、学生、自由职业者 | 低价获取Coding Plan额度、变现剩余额度 | 聚焦火山方舟Coding Plan（¥40入门）、智谱GLM Coding Plan（24.2万付费用户基数），验证双边市场流动性 |
| **第二阶段（规模化）** | 中小企业、AI-first初创公司 | 多平台额度聚合管理、成本优化、内部池化 | 推出企业SaaS额度管理工具，帮助企业实现跨平台额度可视化、智能预警、剩余额度自动挂售 |

MVP阶段优先覆盖 **火山方舟Coding Plan、智谱GLM Coding Plan、阿里云百炼Coding Plan、MiniMax Coding Plan、Kimi Coding Plan**，并预留 **Claude Code、GPT** 等国际平台的扩展接口。选择这些平台的核心逻辑在于：额度透明（明确标注调用次数）、API Key可直接调用（非IDE插件锁定）、浪费率极高（三层限流导致利用率<5%）。

## 1.4 商业模式与财务框架

TokenMarket 构建 **"交易利差为核心、多元收入为补充"** 的四层盈利体系：

| 收入来源 | 模式描述 | 收入占比预估 |
|---------|---------|------------|
| **交易利差（核心）** | 买家统一价（官方价85%）− 卖家折扣价（官方价70%）= **15%平台利差** | ~60% |
| **买家会员订阅** | 月费¥19–¥49，享受折扣价+优先取用+高级路由 | ~20% |
| **企业SaaS** | 帮助企业做内部额度管理和池化（卖工具而非卖额度） | ~15% |
| **增值服务** | 匿名化使用数据报告、API性能监控、多模型对比评测 | ~5% |

根据单位经济模型测算，假设平台月活卖家达 **5万人**、平均挂售额度¥100、挂售转化率50%，平台月GMV可达 **¥175万元**，月毛利（综合20%）约 **¥35万元**，年化毛利约 **¥420万元**。当活跃卖家规模扩展至 **50万人** 时，年化毛利有望达到 **¥4,200万元**。这是一个典型的**双边网络效应市场**——卖家越多，买家选择越丰富、价格越低；买家越多，卖家额度越好卖、变现效率越高。

## 1.5 竞争格局与差异化优势

TokenMarket 所处的竞争格局呈现出 **"直接竞品稀缺、间接竞品众多"** 的特征：

| 竞品类型 | 代表玩家 | 核心差异 | 威胁度 |
|---------|---------|---------|--------|
| **直接竞品：国际B2B大额** | AI Credits（$20M+交易额）、CreditSwap（Private Beta） | 做大额账户/凭证转移，不做C2C小额碎片化 | 中 |
| **直接竞品：国内灰色中转** | 4SAPI、88code、PoloAPI | 价格低（官方10%–30%）但无信任、无保障、随时被封 | 高（用户教育） |
| **间接竞品：API聚合网关** | OpenRouter（500万+用户，$13亿估值）、硅基流动（1000万+用户） | 解决"接入"问题，不解决"浪费"问题 | 低 |
| **间接竞品：成本监控SaaS** | Helicone、Langfuse | 帮用户"看见浪费"，不帮用户"交易浪费" | 低 |

TokenMarket 的核心差异化优势包括：**全球C2C额度交易市场空白**（无同类型竞品）、**合规+信任+担保机制**（escrow+评价+保险池，区别于灰色市场）、**积分体系提高留存**（卖家存入额度获得平台积分，积分可跨期累积、跨平台兑换）、**以模型为标的统一价**（买家按模型能力付费，消除"买到劣质额度"的不确定性）。

## 1.6 发展路径与融资需求

TokenMarket 制定了 **三阶段递进式发展战略**：

- **Plan A（个人撮合，0–12个月）**：验证C2C双边市场模型，建立核心用户群和交易流动性，目标覆盖国内主要Coding Plan平台。
- **Plan B（企业额度管理SaaS，12–24个月）**：当平台方可能推出官方池化功能时，快速转向企业级SaaS工具，帮助企业实现跨平台额度聚合、智能预警、自动优化——从"撮合交易"升级为"管理工具"。
- **Plan C（开源模型聚合，24个月+）**：构建开源模型+商业模型的混合聚合层，降低对单一平台API的依赖，建立长期技术护城河。

当前项目处于 **天使轮/Pre-A轮** 融资阶段，本轮融资将主要用于：MVP技术研发（API网关、智能路由、Key隔离系统）、首批平台接入与合规架构设计、双边市场冷启动（卖家招募+买家获客）、以及信任机制与积分体系的产品化。TokenMarket 面临的核心时间窗口约为 **6–12个月**——在平台方推出个人用户池化功能之前，建立足够的用户粘性和网络效应，从而在市场演变中占据主动地位。

> **总结**：TokenMarket 以技术创新驱动商业模式革新，将国内AI编程助手市场中每年6–10亿元的结构性浪费转化为可持续的平台价值。通过C2C实时撮合、技术代理隔离和智能路由系统，TokenMarket 不仅为个人开发者和中小企业提供了降低成本、提高利用率的有效途径，更有望成为全球AI额度交易基础设施的先行者。
