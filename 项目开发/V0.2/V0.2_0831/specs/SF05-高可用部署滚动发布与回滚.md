# SF05 高可用部署、滚动发布与回滚

**优先级：** P0　**依赖：** SF02、SF03、SF04

## 功能描述

提供 test/prod 可复现的高可用部署、零停机滚动升级、数据库兼容迁移、备份恢复和一键可执行回滚流程，满足数据面 99.9% 与 RPO/RTO 目标。

## 功能要求

- 延续分层 Compose/镜像契约并形成生产拓扑；至少两个数据面副本，健康检查和资源限制明确。
- 镜像以不可变 digest 部署，配置/秘密外部注入且日志脱敏。
- schema 采用 expand/migrate/contract；应用回滚期间新旧版本均可读写兼容数据。
- PostgreSQL 自动备份并验证恢复；Redis 仅恢复可重建状态。
- 运行手册覆盖发布、停止条件、回滚、密钥轮换、灾难恢复和联系人。

## 边界与异常

V0.2 不以 Git 分支推断环境；`mode=test|prod` 必须显式。回滚不得删除账本或用量事实，不得用未验证备份宣称满足 RPO。

## 验收标准

1. 同一 commit 可重复构建得到可追踪镜像并通过供应链/漏洞门禁。
2. 滚动升级期间持续基准流量成功率 ≥99.9%，无协议响应格式变化。
3. 前向迁移、应用回滚、迁移重试和最终收缩均通过隔离数据库演练。
4. 从备份恢复到新环境，数据点损失 ≤5 分钟且 30 分钟内恢复服务。
5. 随机终止单个应用副本不会造成整体不可用。
6. 未提供 prod 必要秘密或使用默认秘密时部署在启动前失败。

## 验收证据

部署清单、digest、滚动曲线、迁移矩阵、恢复计时、备份校验和运行手册演练记录。
