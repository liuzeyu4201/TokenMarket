# SF08 Web 设计系统与统一应用壳

**优先级：** P0　**依赖：** SF06、SF07

## 功能描述

将占位前端升级为统一、响应式、可访问的产品界面，覆盖公开站、认证页和登录后应用壳，为后续买家/卖家功能提供稳定导航、反馈和权限呈现基础。

## 功能要求

- 定义颜色、排版、间距、状态和交互 token，以及表单、表格、弹窗、通知、错误边界等基础组件。
- 公开站清楚说明三协议原生透传、共享/专享模式和测试额度边界。
- 应用壳提供全局导航、面包屑、工作区标识、账户安全、通知和全局异步状态。
- 所有页面统一处理 loading、empty、partial error、forbidden、rate limited 和 offline。
- 桌面与移动关键视口可用，满足 WCAG 2.2 AA。

## 边界与异常

不在本 SF 实现业务数据操作；不得用静态假数据伪装已完成业务功能。无权限菜单可隐藏，但服务端仍必须独立鉴权。

## 验收标准

1. 公共组件有可视状态清单和自动化交互测试，无重复私有实现核心组件。
2. 公开站、认证页、应用壳在 360px、768px、1440px 视口无阻断或横向溢出。
3. 键盘可完成导航、表单和弹窗操作，焦点顺序/恢复正确。
4. 自动可访问性扫描无 serious/critical，人工检查满足 WCAG 2.2 AA 关键项。
5. Chrome、Safari、Edge 当前稳定版关键页面无阻断错误。
6. 未完成业务入口明确标记不可用，不提交会失败的假操作。

## 验收证据

组件目录、三视口截图、浏览器矩阵、axe/人工可访问性记录和前端测试报告。
