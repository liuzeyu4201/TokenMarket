# V0.2 Source Feature 实现文档

本目录保存 V0.2 的 34 个 Source Feature（SF）实现文档。它们是后续创建根目录 `specs/NNN-*` 的需求来源，不是一个巨型 Spec Kit 功能。

实施时按 [功能清单与依赖矩阵](../功能清单与依赖矩阵.md) 分批推进。一个根 Spec Kit 功能只映射一个 SF；如果实现调研表明 SF 仍过大，可以继续拆分，但不得合并成 V0.2 总 Spec。

每个 SF 均须写明目标、用户价值、范围、功能要求、异常边界、验收标准和证据。跨功能的共同约束以版本总纲、协议兼容基线、交易沙盒规则和测试发布总则为准。
