# SF12 Project 代理 Key 与权限范围

**优先级：** P0　**依赖：** SF03、SF10、SF11

## 功能描述

允许买家为 Project 创建可撤销代理 Key，并按协议、模型、来源 IP、额度和过期时间收窄权限。Key 只展示一次明文，服务端仅保存不可逆验证材料。

## 功能要求

- Key 固定归属一个 Project；权限交集不得超过 Project/Binding 能力。
- 支持名称、协议集合、模型 allowlist、CIDR allowlist、周期额度、过期时间和状态。
- 创建时只返回一次明文；列表只显示前后缀和元数据，支持轮换、禁用、撤销。
- 鉴权使用抗时序泄漏比较；失败原因对外不暴露 Key 是否存在。
- 每次代理记录 key ID，不记录明文；Web 单会话变化不影响 Key。

## 边界与异常

Key 不是 upstream credential，不能在管理 API 中换取连接密钥。已撤销 Key 不可恢复，只能新建。

## 验收标准

1. 数据库、日志、trace、错误平台均找不到创建后 Key 明文。
2. 协议、模型、IP、额度、过期限制分别有允许/拒绝测试，组合取最严格交集。
3. 撤销在 1 秒内对所有 Gateway 生效；已建立流按明确策略结束。
4. 并发达到周期额度边界时不超扣，误差为 0 个已接受请求。
5. Key 列表和审计仅显示安全前后缀，无法据此认证。
6. 跨 Project 使用或篡改 key ID 均失败且不泄漏资源信息。

## 验收证据

秘密扫描、限制矩阵、并发额度测试、撤销计时、轮换 E2E 和权限测试。
