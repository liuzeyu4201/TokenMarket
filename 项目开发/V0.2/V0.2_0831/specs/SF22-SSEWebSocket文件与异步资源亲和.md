# SF22 SSE、WebSocket、文件与异步资源亲和

**优先级：** P0　**依赖：** SF03、SF04、SF18

## 功能描述

统一处理长连接、上传下载和跨请求资源生命周期，确保背压、取消、大小限制、计量以及“资源必须回到创建它的 Connection”均正确。

## 功能要求

- SSE 不缓冲完整响应，保持事件边界和顺序，支持 backpressure、heartbeat/idle timeout 和客户端取消。
- WebSocket 原生转发握手、双向帧、关闭码和错误；连接建立后固定 Connection。
- multipart/二进制上传下载流式处理，限制大小、速率、内容类型和总时长，不落地明文临时文件。
- 文件、batch、cache、fine-tuning、operation 等资源在创建响应中登记 provider resource ID→Connection/Project 亲和。
- 后续查询、取消、下载、删除按亲和解析；映射不存在/冲突时失败关闭，不重新随机路由。

## 边界与异常

共享模式只允许目录标记 stateless 的端点；需要跨请求亲和的端点要求 dedicated。人工更换专享 Connection 不迁移既有厂商资源。

## 验收标准

1. 500 SSE/WebSocket 并发运行 2 小时，异常断开率 ≤0.5%，内存无无界增长。
2. 慢客户端触发背压/超时时不会拖垮其他连接或无限缓存。
3. 超限上传在读取完整正文前终止，并清理全部临时状态。
4. 创建后资源的查询/取消/下载 100% 回到原 Connection。
5. 缺失亲和映射返回确定错误，绝不尝试另一连接。
6. 连接断开、重连、节点重启后的计量事件完整且不重复结算。

## 验收证据

长连接 soak、内存曲线、慢消费者测试、上传限制、资源亲和 E2E 和节点故障测试。
