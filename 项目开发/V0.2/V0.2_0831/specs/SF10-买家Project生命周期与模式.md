# SF10 买家 Project 生命周期与模式

**优先级：** P0　**依赖：** SF09

## 功能描述

Project 是买家使用平台的隔离、授权、预算和路由边界。创建时选择 `shared` 或 `dedicated`，一个 Project 可启用多个协议，但整个 Project 只能使用一种模式且创建后不可修改。

## 功能要求

- 支持创建、查看、重命名、归档和删除前检查；名称在账号内可辨识，ID 全局不可猜测。
- 创建时必须明确模式并展示后果；模式写入不可变字段，API 不提供 update mode。
- Project 状态至少为 draft、active、suspended、archived；状态机限制可执行动作。
- 启用协议前检查相应 Provider Binding；停用协议不删除历史用量和账本。
- 删除采用受约束的逻辑终止：存在有效 Key、在途任务、资源或未结算分录时拒绝。

## 边界与异常

模式迁移通过创建新 Project 完成；平台不自动复制上游有状态资源。归档后禁止新代理请求，但保留查询和审计。

## 验收标准

1. shared/dedicated 创建、状态转换和所有非法转换均有测试。
2. API、UI 和数据库均不能修改既有 Project mode。
3. 多协议 Project 的每个协议独立校验 Binding，但共享同一 Project 模式。
4. 存在有效依赖时删除返回具体阻塞项；清理后可归档。
5. 跨账号猜测 Project ID 不能区分不存在与无权访问，且无数据泄漏。
6. 归档 Project 的所有 Key 在 1 秒内停止接受新请求。

## 验收证据

状态机测试、数据库约束、权限负向测试、UI 流程和归档传播计时。
